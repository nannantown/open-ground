The problem課題

The most powerful tool you own has the poorest UI. いちばん強い道具の UI が、いちばん貧弱。

Terminal AI agents like Claude Code are the strongest way to build — and they live in a bare terminal. Every project means another cd, another claude, another window. Run a handful at once and your attention dissolves into tab-switching. Nobody bridged that power to a many-projects UI. OPEN GROUND is the bridge. Claude Code のようなターミナル AI エージェントは、最も強力な作り方 ── なのに棲み家は素のターミナル。プロジェクトごとに cd して claude、またウィンドウが増える。数本を同時に回した瞬間、頭のリソースはタブの切り替えで溶けていく。このパワーを「複数プロジェクトの UI」へ橋渡しした者はいなかった。OPEN GROUND がその橋になる。

Your repos, your rulesリポジトリとの距離感

Untouched by default. Shared when you say so. 基本は、何も書き込まない。共有したい時だけ、git で。

Register any folder, anywhere on disk. Out of the box, all OPEN GROUND data lives centrally in ~/.openground — your working tree never gains a dotfile. And when teammates join, flip one switch: the project's Board and Canvas move into the repo and travel through git itself. ディスク上のどこにあるフォルダでも登録できる。素の状態では、OPEN GROUND のデータはすべて ~/.openground に集中管理され、作業ツリーに dotfile は1つも増えない。そして仲間が加わったら、スイッチを1つ ── そのプロジェクトの Board と Canvas はリポジトリに引っ越し、git そのものに乗って共有される。

Default — soloデフォルト ── ソロ

Zero files written into your projects.プロジェクトには1ファイルも書き込まない。

Everything lives in ~/.openground, keyed by a stable ID that survives renames and moves. Your git history never sees us.すべて ~/.openground に置かれ、リネームや移動に耐える安定 ID で紐づく。git 履歴に痕跡は残らない。

  • Local-first, single-user macOS app — your code and sessions never leave your machine.ローカルファーストの macOS アプリ ── コードもセッションもマシンの外に出ない。
  • Subscription-only: drives the claude CLI you already pay for. No API key, no metered bill.サブスク専用：契約済みの claude CLI をそのまま使う。API キーも従量課金も無し。
  • A curated registry, not a scan — remove a card without touching the folder.スキャンではなくレジストリ ── フォルダに触れずカードだけ外せる。
Opt-in — Share via Gitオプトイン ── Git で共有

Build the board together, over plain git.ボードもキャンバスも、素の git でチーム共有。

Enable sharing and the Board + Canvas data moves into .openground/ inside the repo. A teammate clones, imports the folder — and sees the same board. Zero setup on their side.共有を有効にすると、Board と Canvas のデータはリポジトリ内の .openground/ へ。仲間は clone してフォルダをインポートするだけで、同じボードが見える。相手側の設定はゼロ。

  • Pure git. No accounts, no tokens, no API — your existing remote and your own git auth. Works with GitHub, GitLab, anything.純 git。アカウントもトークンも API も不要 ── 既存の remote とあなたの git 認証だけ。GitHub でも GitLab でも動く。
  • One-click Sync. Commit → pull → push, scoped strictly to .openground/ — your staged code changes are never touched.Sync はワンクリック。commit → pull → push を .openground/ だけに限定 ── ステージ済みのコード変更には絶対に触れない。
  • Reversible. Stop sharing and the data moves back to central storage. Personal state (tab order, active canvas) never enters the repo.いつでも戻せる。共有を解除すればデータは中央管理へ帰る。個人の状態（タブ順・表示中キャンバス）は最初からリポジトリに入らない。

How it works使い方

Up and running in three steps. 3ステップで動き出す。

  1. 1

    Put your projects on the groundプロジェクトを大地に並べる

    Create a new project or import any existing folder from anywhere on disk. Each one becomes a card on the canvas — nothing is written into the folder itself.新規プロジェクトを作るか、ディスク上の任意のフォルダをインポート。それぞれがキャンバス上のカードになる ── フォルダの中には何も書き込まれない。

  2. 2

    Click a card, get a terminalカードをクリック、ターミナルが開く

    One click opens a real claude terminal already in that project's folder. Or plan first on the Board and press ▶ on a task.ワンクリックで、そのプロジェクトのフォルダに座った本物の claude ターミナルが開く。先に Board で計画して、タスクの ▶ から始めてもいい。

  3. 3

    Read the ground, steer the fleet大地を読み、艦隊の舵を取る

    Zoom out: beacons show every card where Claude is at work. Drop into any session, answer its question, launch the next one.ズームアウトすれば、Claude が働いているカードにビーコンが灯っている。気になるセッションに降りて、質問に答え、次を起動する。
