Privacy Policyプライバシーポリシー

Last updated: 2026-10-15最終更新：2026-10-15

OPEN GROUND is a desktop workspace. Local project metadata is stored on your computer. AI use and optional integrations also make network connections; local storage does not mean that every action stays off-network.

1. Local files and AI use

The project registry, preferences, Board and Canvas data, assets, custom modules, blog records and Assistant records are stored under ~/.openground/, or the configured data root. Source files and research reports remain in project folders. Electron keeps additional UI state in its app profile; Claude and NENE own separate data stores.

Claude Code and Agent SDK sessions use your own installed Claude and account. Prompts, files read by the model and tool requests may be sent to the AI provider under that account. OPEN GROUND does not include an AI subscription, a shared provider account or an AI API-key setup. Terminal commands and custom content may also contact services you use.

2. Optional app account and billing

Free local project and terminal use does not require an OPEN GROUND login. Optional Google/GitHub login uses Supabase; account identifiers and membership information are processed there. App login is separate from your Claude login.

For OPEN GROUND Pro, Stripe processes payment details. Subscription records in Supabase include the account ID, Stripe customer ID, status, billing-period end and cancellation status. Card numbers are handled by Stripe, not stored by the desktop app. Billing requests do not include project files or terminal conversations.

Cancellation is managed through the app's billing portal. An unavailable contract check, work mode, uninstalling the app or deleting local data does not cancel an existing subscription. Local project data is retained when Pro expires. Cloud billing records are separate from local backups.

3. Sharing and Owner integrations

When configured and enabled, collaboration sends the shared Board and eligible Canvas data to the collaboration service (Supabase and Cloudflare). This can include notes, images, and source you put in a mock/screen element. It is not a repository-code sync, but shared content may itself contain code or personal information.

Owner WordPress integration sends selected research reports to the configured site as drafts and authenticates with its application password. Phone linking uses a separate relay and optional Apple push notifications. External media, research tools and custom frames may contact their content providers. Songs uses the separately installed NENE application.

4. Updates and feedback

Update checks and downloads contact GitHub release infrastructure. Sending feedback submits the message, any attached images and included app/platform/contact information to the configured feedback service. Do not submit passwords, tokens, private conversations or unredacted backups.

5. Controls and backups

Work mode blocks app-managed non-Anthropic connections, including sign-in, billing checks, updates and sharing. It is not a universal network sandbox for arbitrary commands. Turn it off to use those connections again, including billing management.

Settings and their automatic generations can contain WordPress credentials. File permissions restrict them, but they are not an encrypted full-workspace backup. Disconnecting WordPress removes the active setting; old generations may retain it. Revoke the password at WordPress when it should no longer work.

Automatic generations cover the registry/settings and Ground layout only. Back up the full app data, profile and required project/external data separately. Share only redacted diagnostics with support. Use the in-app feedback form when configured, or the project's GitHub page for public questions; do not post private removal requests or secrets in public issues.

OPEN GROUNDはデスクトップの作業環境です。プロジェクトの管理データは手元に保存しますが、AI利用や任意の連携には外部通信もあります。ローカル保存は、すべての操作が通信しないことを意味しません。

1. ローカルデータとAI利用

登録一覧、設定、Board・Canvas、画像、自作タブ、ブログ記録、Assistant記録は、~/.openground/または設定した保存先に置きます。コードや調査レポートは各プロジェクト内に保存します。画面の状態はElectronのアプリ用プロファイルにも保存され、ClaudeとNENEは別にデータを管理します。

Claude CodeとAgent SDKのセッションは、本人のインストール済みClaudeとアカウントを使います。プロンプト、モデルが読むファイル、ツールへの指示は、そのアカウントを通じてAI提供元へ送られる場合があります。OPEN GROUNDにAIサブスクや共用アカウントは含まれず、AI用APIキーの設定方式も提供しません。ターミナルのコマンドやカスタムコンテンツも、利用するサービスと通信する場合があります。

2. 任意のアカウントと課金

Freeのローカルなプロジェクト管理・ターミナル利用に、OPEN GROUNDのログインは必須ではありません。任意のGoogle・GitHubログインにはSupabaseを使い、アカウント識別情報やメンバー情報を扱います。アプリへのログインとClaudeへのログインは別です。

OPEN GROUND Proの決済はStripeが処理します。Supabaseの契約記録には、アカウントID、Stripe顧客ID、契約状態、契約期間終了日、解約状態を保持します。カード番号はStripeが扱い、デスクトップアプリには保存しません。課金の通信にプロジェクトファイルやターミナルの会話は含まれません。

解約はアプリから開く支払い管理画面で行います。契約確認の通信失敗、業務モード、アンインストール、ローカルデータの削除だけでは、継続中の契約は解約されません。Proが失効してもローカルのプロジェクトデータを保持します。クラウドの課金記録とローカルのバックアップは別です。

3. 共有とOwner向け連携

共同編集が設定・有効化されている場合、共有するBoardと利用権限のあるCanvasのデータを、SupabaseとCloudflareを使う共同編集サービスへ送ります。メモ、画像、mock・screen要素に入れたソースが含まれる場合があります。リポジトリ全体のコード同期ではありませんが、共有内容そのものにコードや個人情報を含めることはできます。

OwnerのWordPress連携は、選んだ調査レポートを指定サイトへ下書きとして送り、アプリケーションパスワードで認証します。iPhone連携は別の中継サービスと任意のAppleプッシュ通知を使います。外部メディア、調査ツール、カスタム画面は、各提供元へ通信する場合があります。Songsには別途インストールされたNENEを使います。

4. 更新とフィードバック

更新確認・ダウンロードはGitHubの配布基盤へ接続します。フィードバックを送信すると、本文、添付画像、含めたアプリ・OS・連絡先の情報が、設定された受付サービスへ送られます。パスワード、トークン、非公開の会話、未加工のバックアップは送らないでください。

5. 操作とバックアップ

業務モードは、アプリが管理するAnthropic以外への接続を制限します。ログイン、契約確認、更新、共有も対象です。任意のコマンドを完全に隔離するネットワークサンドボックスではありません。支払い管理などの接続を使うには、業務モードをOFFにしてください。

設定と世代バックアップにはWordPressの認証情報が含まれる場合があります。ファイル権限で制限していますが、暗号化された全体バックアップではありません。WordPressの接続を解除しても、古い世代には値が残る場合があります。使えなくしたいパスワードはWordPress側で失効させてください。

自動世代バックアップの対象は、登録一覧・設定とGroundの配置です。アプリ全体のデータ、画面のプロファイル、必要なプロジェクトや外部アプリのデータは別に保存してください。サポートには必要部分を伏せた診断情報を使ってください。設定されているアプリ内フィードバック、または公開の質問にはGitHubを利用できます。秘密情報や非公開の削除依頼を公開Issueに書かないでください。
