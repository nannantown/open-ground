# Board UX Flows — 夜間ブラッシュアップの作業台帳

> 2026-06-11 23:19 開始 / 2026-06-12 08:00 終了予定の自律改善ループの土台。
> 目的: 「2人の開発者が GitHub 共有プロジェクトを Board で回す」体験を、
> タスク作成 → claude でラン → PR → レビュー → 完了 まで**不安ゼロ**にする。
> 各サイクル: 台帳のフローを歩く → 痛点発見 → Backlog 化 → 実装 → レビュー →
> テスト緑 → main へ push → 台帳更新 → 次サイクル。リリースはしない（push まで）。

## 北極星

ユーザーが各ステップで「**次に何が起きるか**」を マニュアル無しで言えること。
- タスクを作るとき: ランに必要な情報が揃っているとわかる
- ▶ を押すとき: どのブランチ/worktree で何が始まるか見える
- 完了するとき: push → PR が作られることが明示される
- PR が開いたら: カードが自動でレビュー列へ動き、それが通知される
- レビューするとき: PR リンク・差分の要約・確認手順がカードから1クリック

## ループ運用ルール（自分への規律）

1. 1サイクル = 踏査(2〜5フロー) + 実装(1〜3改善) + テスト緑 + push。小さく刻む。
2. 実装の検証は `npm test`+`tsc`+`lint` 必須、UI 変更は Playwright スクショで目視。
3. ユーザーの dev サーバー(5174/47776)は壊さない。HMR で勝手に反映されるのは想定内。
4. git stash 禁止。push は Sonnet 委任。リリース(タグ/publish)はしない。
5. 大きすぎる構想(B 案件で1時間超え)は分割するか idea のまま朝へ持ち越す。
6. 08:00 JST になったら新規着手をやめ、仕掛りを閉じて総括レポートを書く。
