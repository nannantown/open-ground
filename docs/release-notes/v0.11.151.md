# 0.11.151

## Mac の通知が「本当に必要なときだけ」になりました

**実現されること**

- **画面右上の Mac の通知は、次の3つのときだけ出ます。** あなたが答えないと作業が止まる質問が来たとき(最初の1回だけ)、あなた自身の Claude の会話が使用量の上限で止まったとき、パソコンに止まったままの処理がたまって再起動が必要なとき。
- **OPEN GROUND を見ている間は、その3つも Mac の通知には出ません。** 画面の中で見えているためです。
- 更新の準備や進み具合などのお知らせは、これまでどおりアプリ内のベルに残ります。Mac の通知には出なくなるので、更新中にエラーと見間違えることがなくなります。

## 画面の矢印を「く」の形にそろえました

- 戻る・進む・開閉など、画面に出る方向の矢印を、すべて軸のない「く」の形にそろえました。

## Ground の整頓と検索

- **フレームの整頓ボタンで、大きさの違う中身がまとまって並ぶようになりました。** 大きな子フレームの横に小さいカードが縦に積まれ、何度押しても並びが崩れません。フレームは中身にちょうど合う大きさになります。
- **検索の虫めがねを、右上のボタン群の「追加」のすぐ右に移しました。**

## エージェントチーム: 下書きのカード

- **カードに「下書き」の印を付けられるようになりました。** 印がある間は自動で作業が始まらず、Board では薄く表示されます。印を外すとすぐに始まるので、順番のある作業をまとめて書いている途中で先に動き出すことがなくなります。

## Mac notifications only when they really matter

- **The top-right Mac notification now appears in only three cases:** a
  question that stops work until you answer it (first time only), your own
  Claude conversation hitting its usage limit, and stuck processes piling up
  so that a restart is needed.
- **While you are looking at OPEN GROUND, even those three stay out of the
  Mac notification** — you can already see them on screen.
- Update progress and other notices still land in the in-app bell, just not
  as Mac notifications, so an update is no longer mistaken for an error.

## Direction arrows are chevrons everywhere

- Every direction mark on screen (back, forward, open / close) is now a
  plain chevron, never a shafted arrow.

## Ground: tidy and search

- **A frame's tidy button now packs mixed sizes neatly.** Small cards stack
  beside a large child frame, pressing it again never scrambles the layout,
  and the frame fits its contents.
- **The search magnifier moved into the top-right button group, right after
  Add.**

## Agent Team: draft cards

- **Cards can be marked as a draft.** A draft never starts automatically and
  is shown faded on the Board; removing the mark lets it start right away, so
  a set of ordered tasks no longer starts before you have finished writing it.
