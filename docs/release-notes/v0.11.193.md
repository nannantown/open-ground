# 0.11.193

### 日本語

- **タブの並べ替えが、エージェントの作業と重なっても元に戻らなくなりました。** エージェントチームがボードにカードを足したり動かしたりした直後にタブを並べ替える・隠す・付け外しすると、その変更が黙って元に戻ることがありました。今は、タブの並びや表示の設定はそのまま保存されます。アプリの更新や再起動のあとも並び順が保たれることもあわせて確かめました。

---

### English

- **Reordering tabs no longer snaps back when the agent team writes the Board
  at the same moment.** Reordering, hiding, attaching or detaching a tab right
  after the agent team added or moved a card could be silently undone. Your
  tab layout is now kept. Tab order was also confirmed to survive app updates
  and restarts.
