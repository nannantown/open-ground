# 0.11.190

### 日本語

- **アシスタントが、貼ったリンクの中身を読んで答えられるようになりました。** YouTube の字幕、Web ページ、Reddit、GitHub、RSS に対応しています。Web・Reddit・GitHub の検索もできます。iPhone のアシスタントでも同じです。
- 読むだけで、投稿やログインなどの操作はしません。この機械で使えない調査チャンネルは「使えない」と答えます。
- X は、ログイン情報を安全に扱えないため、アシスタントからは読みません。
- このパソコン自身や社内向けのアドレスは読みません。外部の中継サービスにも送りません。

---

### English

- **The assistant can now read what a pasted link says and answer from
  it:** YouTube subtitles, web pages, Reddit, GitHub and RSS. It can also
  search the web, Reddit and GitHub. The iPhone assistant gets the same.
- Read only: it never posts or signs in. A research channel that is not
  set up on this machine is answered as not available.
- X is not read by the assistant, because its sign-in cannot be handled
  safely.
- Addresses on this computer or a private network are never read, and
  never sent to an outside relay.
