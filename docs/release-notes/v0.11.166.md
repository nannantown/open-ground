# 0.11.166

### 日本語

- **「保留」から「やり直す」で再開したカードが、作業が始まったばかりなのに「統合待ち」に上がってしまう不具合を直しました。** 前回の作業の古い「終わりました」という記録を、新しい作業の完了と取り違えていました。今は、やり直した作業が自分で終わったと伝えたときだけ統合待ちに上がります。
- やり直したカードについて、前回の作業の古い質問がもう一度届くこともなくなりました。

---

### English

- **Fixed: a card resumed from the on-hold column with "Redo" could jump to
  "waiting to integrate" right after work restarted.** The engine mistook the
  previous attempt's old "done" record for the new attempt finishing. Now the
  card moves up only when the redone work reports that it has finished.
- A redone card no longer re-sends the previous attempt's old questions.
