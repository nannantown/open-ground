## OPEN GROUND 0.11.99

### 終わった仕事が、司令官に届かないことがなくなりました

worker が仕事を終えても、**カードが「作業中」に取り残されたまま誰も動かさない**ことがありました。カードが動かなければ司令官は起こされず、統合されないまま止まります。worker は生きて見えるので、画面上は進んでいるように見えます。

実測（2026-08-27）: 再起動をまたいだ worker 3体が完了 → カードは作業中のまま → 作業フォルダも心拍も「終わった」と言っているのに、誰も判断待ちへ動かさない → 補給官が手で司令官に声をかけたときだけ、司令官が自分でカードを動かして動き出す。

**通知の仕組みは壊れていませんでした。**「統合待ち 3 件・**0秒**で到達」というログがその証拠で、カードが判断待ちに載った瞬間に通知は出ています。足りなかったのは、**カードを判断待ちに載せる担当**でした。

- **取り残されたカードを engine が回収します** — 誰も担当していない「作業中」のカードで、branch に成果があり、worker が「終わった」と記録しているものを、判断待ちへ移します。あとは今まで通り司令官に通知が飛びます。
- **作業中の worker のカードは触りません** — 担当が付いているカード、成果や完了の記録が無いカード、そして**一度差し戻されたカード**は対象外です。差し戻されたカードは「終わった」の記録が残ったまま再作業に入るので、そこだけは触らないのが安全です。
- **手動で動かした worker にも効きます** — 0.11.98 でカードの **実行** を worker 経路にしましたが、その worker も engine の担当表には載りません。同じ穴を通っていたので、同じ回収で拾われます。
- **拾えなかったものは異常として出ます** — 「担当が居ないのに作業フォルダが残っている」カードが Swarm の異常欄に出ます。健全な手動 worker で誤報しないよう、**本当に誰も居ないことを確かめてから**しか出しません。

> 「声かけが 1 回目で止まる」件も、これと同じ原因でした。判断待ちが空だと engine は声をかける理由を失います — カードが作業中に取り残されていた間、判断待ちはずっと空でした。回収が入れば、10分おきの 1回目 → 2回目 → 3回目がそのまま進みます。

### Finished work always reaches the commander now

A worker could finish and its card would **stay in Doing with nobody to move it**. A card that does not move never wakes the commander, so nothing gets integrated — and because the workers still look alive, the board looks like it is progressing.

Measured 2026-08-27: three workers that spanned an app restart finished; their cards stayed in Doing while the worktree and the heartbeat both said done; the only thing that ever restarted the machine was the owner poking the commander by hand, which made the commander move the cards itself.

**The notification machinery was never broken.** The log line "統合待ち 3 件・**0 seconds** to arrive" is the proof — the moment a card reached the review column the notice fired. What was missing was anyone to put it there.

- **The engine now collects stranded cards** — a Doing card no worker owns, whose branch holds real work and whose worker recorded that it finished, moves to review. From there the existing chain wakes the commander as it always did.
- **A card someone is working on is never touched** — not one with an owner, not one without both a finish record and real commits, and not one that has been **sent back before** (a sent-back card keeps its old "finished" record while it is being reworked, so that case is left alone rather than guessed at).
- **Manually started workers are covered too** — 0.11.98 routed the card's Run button through the worker path, and those workers are not on the engine's roster either. Same hole, same fix.
- **What cannot be collected is reported** — a Doing card with no one driving it but a worktree still on disk now appears in the Swarm anomaly feed, and only after confirming nobody is actually working there, so a healthy manual worker never triggers it.

> The "nudge stops after the first try" symptom had the same cause: with the review column empty the engine has nothing to nudge about, and the stranded cards were exactly why it stayed empty. With them collected, the 10-minute 1st → 2nd → 3rd ladder runs on its own.
