# 0.11.196

### 日本語

- **社長への入力欄を常時表示しました。** Claude と ChatGPT のどちらでも、社長の席の下から続けて話しかけられます。Enter で送信、Shift+Enter で改行します。日本語の変換確定では送信しません。
- Claude の入力欄は、iPhone と同じ配送処理を使います。社長が作業中だったり、ターミナルに入力途中の文字があったりするときは、上書きせず保留します。送信に失敗した文章と、社長の再起動中の下書きは入力欄に残ります。
- 狭いウィンドウで社長の入力欄や文章の先頭が隠れないよう、席の幅を調整しました。バーを畳んで開き直しても、社長への下書きが残ります。
- Claude の社長は従来の実行方式を維持し、ターミナルへの直接入力と Remote Control を引き続き利用できます。従量課金 API への切り替えは追加していません。

---

### English

- **The president's conversation input now stays open.** Keep talking below the president seat with either Claude or ChatGPT. Enter sends, Shift+Enter adds a line break, and IME composition never sends a message.
- Claude messages use the same guarded delivery lane as the iPhone. Busy desks and unfinished terminal input hold a message without overwriting it. Failed sends and drafts during a president restart remain in the input.
- President seats fit narrow windows so the input and the beginning of the message remain visible. Folding and reopening the team bar preserves the president's draft.
- Claude presidents retain their existing runtime, direct terminal input and native Remote Control. No metered API fallback has been added.
