# 0.11.174

### 日本語

- **作業の差し戻し回数が、利用枠の停止をはさんでも正しく数えられるようになりました。** これまでは、利用枠の上限で作業が止まって頼み直すたびに回数が 0 に戻り、「何度直しても通らない作業は保留にして相談する」安全装置が効きにくくなっていました。今は利用枠の停止や再起動では続きから数え、オーナーが「やり直す」と決めたときだけ 0 に戻ります。
- **Ground 画面で、アシスタントのロゴを左下のペンのボタンと同じ高さの右端に置きました。** プロジェクト画面では、これまでどおりエージェントチームのバーに重ならない位置です。自分で動かした位置はそのまま残ります。

---

### English

- **The rework count now survives usage-limit pauses.** Before, every time a
  worker hit the usage limit and was restarted, the count went back to zero,
  so the safeguard that parks a card that keeps failing review (and asks the
  owner) rarely triggered. Usage-limit pauses and restarts now keep counting;
  only the owner's own "retry" decision resets it.
- **On Ground, the assistant's logo now sits at the right edge, level with the
  pen button at the bottom left.** In a project it stays clear of the agent
  team bar as before, and a spot you dragged it to is kept.
