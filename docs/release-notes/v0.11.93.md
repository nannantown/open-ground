## OPEN GROUND 0.11.93

### 要点は待たずに出る・質問はいつでも手元に(Research)

0.11.92 の直後にオーナーから3つの注文:「要点はデフォルトでだしておこう。質問はボトムにstickして。縮小もできるように(デフォルトは表示)。入力フォームのデザインださいよね」。全部入れました。

- **要点が自動で出る** — 要点のないレポートを開くと、ボタンを押さなくても抽出が始まります(1レポート1回だけ。失敗してもループしません)。作り直しはこれまで通り明示ボタンのみ。
- **質問ドック** — 質問ボックスがレポート下部に常駐。本文をどこまでスクロールしても手元に残ります。ヘッダーのボタンでたためて、開いた状態がデフォルト。Q&Aはドック内で時系列に並び、新しい回答が入力欄のすぐ上に来ます。
- **入力フォーム刷新** — くぼんだ入力面+内蔵の送信ボタン。フォーカスするとアクセント色に発光します。TL;DR は見出し書体になり、カードが読み物らしくなりました。

### Key points appear on their own; the question box stays at hand (Research)

Three orders from the owner right after 0.11.92: key points by default, the question box pinned to the bottom (collapsible, shown by default), and a better-looking input form. All in.

- **Auto-distilled key points** — opening a report that has none starts the distill on its own (once per report; a failure never loops). Redo remains an explicit button.
- **Question dock** — the Q&A now lives in a dock pinned to the reader's bottom edge, staying at hand however far you scroll. Fold it with one click; it opens by default. Entries run chronologically with the newest right above the composer.
- **Composer redesign** — an inset field with an embedded send button that glows in the accent color on focus. The TL;DR now wears the display face, so the card reads like a headline.
