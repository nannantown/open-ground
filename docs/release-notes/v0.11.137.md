# 0.11.137

## 自動アップデートが「操作中」と誤って判定され続けて入らない問題を修正

**実現されること**

- **自動アップデートを ON にしておけば、アプリを前に出したままでも、新しい版がおおむね1時間以内に入れ替わるようになりました。** これまでは、マウスを定期的に動かすアプリ(スリープ防止など)がカーソルを少し動かすたびに「操作中」と判定され、更新が1時間以上入らないことがありました。
- 「操作中」と数えるのは、キー入力・クリック・スクロールなど本当の操作だけになりました。カーソルが乗っている・動いただけでは数えません。
- それでも見送りが続いた場合は、ダウンロードから45分たったところで、文字を打っている最中の数秒だけを避けて入れ替えます。文章を打っている途中で切られることはありません。

---

## Auto-update no longer waits forever on a false "owner active"

- **With auto-update on, a new version now goes in within about an hour, even
  with the app in front all day.** A keep-awake mouse jiggler nudging the
  cursor every few minutes used to read as "the owner is working" and could
  hold an update for over an hour.
- Only real input — keys, clicks, scrolling — counts as the owner being
  active. A cursor merely resting on or moving over the window does not.
- If the update is still being held 45 minutes after it downloaded, it goes in
  at the next moment you are not typing, so a sentence is never cut off.
