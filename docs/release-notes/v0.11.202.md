### English

- Fixed Claude subscription sign-in being lost when OPEN GROUND explicitly supplied the default configuration directory. Ordinary CLI sign-in is now preserved; explicitly configured directories remain supported. The target subscription is checked before retiring the current team, without API-key fallback.
- President panes now show connection switching and its recovery controls. Starting or restarting a president waits for a stable connection, SDK replacement handles are retained, and a failed status read no longer leaves an accepted switch stuck on screen.
- A saved native history that cannot be inspected is reported individually instead of hiding every recovery item. Unconfirmed work remains held; an unreadable history cannot be marked reviewed through this display.

### 日本語

- OPEN GROUNDが標準の設定場所を明示すると、通常のClaude Codeの契約ログインが見えなくなる問題を修正しました。明示的なカスタム設定は保持し、切り替え先の契約ログインを確認してから既存チームを終了します。APIキーへの切り替えは行いません。
- 社長の画面で接続切り替えの状態と復旧操作を確認できるようにしました。切り替え中の起動・再起動を抑止し、SDKの新しい接続を引き継ぎます。一時的な状態取得の失敗後も表示を再取得します。
- 古い履歴を読み取れない場合、その履歴の確認が必要なことを個別に表示し、ほかの復旧項目まで隠さないようにしました。結果不明の作業は保持し、読めない履歴を確認済みにはしません。
