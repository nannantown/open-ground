### 日本語

- オーナー専用の Claude／ChatGPT 切替で、現在の実行先と切替先・進行状況を表示します。作業の安全な区切りで会話・待機指示・Board・作業ブランチを引き継ぎ、起動できない場合は再試行または切替の取消ができます。

### English

- Owner-only Claude / ChatGPT switching shows the effective provider, requested provider and progress. Handoffs wait for a confirmed safe boundary and preserve conversation, queued instructions, Board and working branches. Failed starts offer retry or cancellation.
- Assistant and president drafts and accepted instructions survive restarts and reconnections. Retrying an instruction does not execute it twice, and late acknowledgements cannot erase a newer draft.
- Stop turn, new conversation, delete memory and delete history have separate effects. Unconfirmed operations wait for inspection; a reset never claims to undo changes already performed.
- The iPhone connection adds conversation/delivery recovery and capability-checked switching and stop controls while retaining older client compatibility. Execution uses the owner's subscription; there is no metered API or API-key fallback.
