# 0.11.191

### 日本語

- **アシスタントで、モデルと考える深さを自分で選べるようになりました。** 入力欄の横の調整ボタンから選びます。何も選ばなければ今まで通り「自動」です。
- 選んだ内容は覚えていて、iPhone のアシスタントにも同じように効きます。
- 設定の「使ってよいモデル」で外したモデルは選べません。選んでいたモデルが外されると自動に戻ります。

---

### English

- **You can pick the assistant's model and how hard it thinks.** Use the
  adjust button next to the input. Nothing picked means "auto", as before.
- The pick is remembered and applies to the iPhone assistant too.
- A model turned off in Settings' usable models can't be picked; a picked
  model that gets turned off goes back to auto.
