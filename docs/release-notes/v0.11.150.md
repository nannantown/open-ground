# 0.11.150

## 社長への知らせが入力欄で止まらなくなりました

**実現されること**

- **司令官の返事やエンジンの知らせが、社長の入力欄に残ったまま止まらなくなります。** 社長の席が小さくて長い知らせの一部しか見えないときも、送信まで届きます。
- **あなたが入力欄に何か打っていたら、知らせは決して送られません。** あなたの文を消したり、混ぜたりもしません。
- **フォルダ名の大文字・小文字が違うプロジェクトでも、司令官の返事が社長に届くようになりました。**

---

## Notices no longer get stuck in the president's input box

- **Commander replies and engine notices no longer sit unsent in the
  president's input box**, even when the seat is small and shows only part
  of a long notice.
- **If you have typed anything into the box, a notice is never sent** — and
  your text is never erased or mixed in.
- **Commander replies now reach the president in projects whose folder name
  differs only in upper / lower case.**
