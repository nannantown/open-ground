## OPEN GROUND 0.11.107

### 「今すぐ再起動」が、本当に再起動するようになります

何度再起動しても同じ「ダウンロードしました」の画面が出て、いつまでも新しい版にならない不具合を直しました。

- **「今すぐ再起動」を押すと、そのまま終了して新しい版で立ち上がります。** これまでは押しても終了せず、画面だけが動かなくなり、手で終了すると落としたばかりの更新が捨てられていました（毎回同じことの繰り返し）。
- **万一また適用できなかったときは、黙って失敗しません。** 「適用できませんでした／更新は入っていません」とはっきり出て、リリースページを開くボタンが付きます。データはそのまま残ります。
- **設定の「自動アップデート」をオンにしておくと、離席中に自動で入ります。** オフのままでも上のとおり正しく動きます。

⚠ **今回の1回だけは手で入れてください。** いま入っているアプリにこの不具合があるため、この版だけはリリースページから .dmg を落として上書きしてください。次からは「今すぐ再起動」で更新できます。

### "Restart now" actually restarts

Fixed the bug where the same "has been downloaded" dialog came back after every restart and the new version was never installed.

- **Pressing "Restart now" now quits and comes back on the new version.** It used to not quit at all: the window froze, and quitting by hand threw away the update that had just been downloaded — on every single launch.
- **If an install ever fails again, it will not fail silently.** The app says "the update could not be applied / it is not installed" and offers the release page. Your data is left untouched.
- **With "Automatic updates" on in Settings, updates land while you are away.** With it off, the path above now works correctly.

⚠ **This one version has to be installed by hand.** The copy you are running carries the bug, so download the .dmg from the release page once. "Restart now" works from then on.

**Cause** (for the record): on macOS, electron-updater's `autoInstallOnAppQuit` is not "install on quit" — install-on-quit lives in `BaseUpdater` (Windows/Linux), while `MacUpdater extends AppUpdater` and has no quit handler. The flag's only macOS effect is whether the downloaded zip is handed to Squirrel.Mac at download time. It was being driven by the user's hands-free-update setting, so with that setting off nothing was ever handed over, and `quitAndInstall()` returned without quitting.
