## 生成した説明が消える問題を根治しました(ほか2件)

### 1. プロジェクトの説明が「気がついたら消えている」

原因は2つ重なっていました。

- **保存のたびにペアが消えていた期間があった。** 説明は日英ペアで生成されますが、
  6/10〜8/3 の版では保存の検査がこのペアを知らず、どんな保存でも
  ディスクから静かに消えていました(8/3 に修正済み)。
- **今も、ファイルに型崩れが1箇所あると消えていた。** tasks.json のどこかに
  1つでも壊れた値があると、読み込みが救済モードに落ち、その救済が
  説明ペア(と config / launch 等)を拾い忘れていました。次の普通の保存で
  消失が確定します。実機で再現・修正済み — 救済はスキーマが知る全項目を
  1項目ずつ拾うようになり、新しい項目も自動で守られます。
- **消えた後の「空白」も直しました。** 片言語しか残っていない説明は、UI言語と
  合わないと何も表示しない仕様でした。今は残っている文があれば必ず表示します
  (完全に無いときだけ「説明を生成」ボタン)。

**AIResearch などで消えてしまった説明は、もう一度「説明を生成」を押せば
日英ペアが入り直し、以後は消えません。** 型崩れで退避されたファイルは
`tasks.corrupt-<数字>.json` として同じフォルダに残っています。

### 2. WAITING は「あなたの入力が要るときだけ」

「途中でとまってても waiting」をやめました。琥珀色のランプが意味するのは
**未回答の質問がある**、この1つだけです。寝かせた判断待ちカードや止まっている
作業ではもう点きません(質問は Swarm タブの質問ペインで答えられます)。

### 3. 調査タブの名前を英語に

日本語設定でもタブ列は英語の並び(BOARD / SWARM / …)なので、「調査」だけ
日本語だったタブ名を **Research** に揃えました。中身は日本語のままです。

## The vanishing project descriptions, fixed at the root (plus two)

### 1. Generated descriptions no longer disappear

Two stacked causes:

- **A window where every save erased the pair.** Descriptions generate as a
  ja/en pair; between Jun 10 and Aug 3 the save-path schema didn't know the
  pair fields, so any save silently dropped them from disk (fixed Aug 3).
- **Still live until now: one type flaw erased them too.** A single broken
  value anywhere in tasks.json pushed reads into field-level recovery, which
  forgot to salvage the description pair (and config/launch). The next
  ordinary save made the loss permanent. Reproduced on the prod build and
  fixed — recovery now salvages every schema-known field, one by one, so
  future fields are covered automatically.
- **The blank after the loss is fixed too.** A surviving single-language
  description used to render as nothing under the other UI language; any
  surviving text now always shows (the generate button appears only when
  there is truly none).

**Press 説明を生成 once on affected projects to refill the pair — it will
stick now.** Quarantined originals remain as `tasks.corrupt-<n>.json`.

### 2. WAITING only when your input is needed

The 「途中でとまってても waiting」 rule is retired. The amber lamp now means
exactly one thing: **an unanswered question for you** (answered in the Swarm
tab's question pane). Parked decision cards and stalled work no longer light
it.

### 3. Research tab named in English

The tab strip is an English row even in the Japanese UI, so the one
Japanese label (調査) became **Research**. The tab's contents stay Japanese.
