## OPEN GROUND 0.11.110

### 子リポに成果を出した worker が「完了」と認められるようになります

複数の独立したリポジトリを束ねた親フォルダをプロジェクトにしていると、worker は成果を親ではなく子リポ（入れ子のワークツリー）に出します。これまでエンジンは親ブランチのコミットしか数えていなかったため、完成して「done」と申告した worker を「停止」扱いで 10 分つつき続け、完成品が 26 分放置されました（2026-09-13 実測）。

- **子リポ／入れ子ワークツリーのコミットも「成果あり」と数えます。** 親ブランチが 0 でも、worker の作業フォルダ直下の別リポにコミットがあれば review に上がり、司令官に届きます。
- **成果の場所がジャーナルに出ます。**「成果の所在: 入れ子リポ .trending-wt / .figma-wt に 2 コミット（親ブランチは 0）」— 司令官が親ブランチを見て「何も無い」と誤読しないように。
- **本当にどこにもコミットが無い「done」は、黙って停止扱いにしません。** 初見でお知らせ（鐘）とジャーナルに出し、3 分は声をかけずに待ち（完了した worker への「続けて」は答えさせるだけで意味がない）、それでも無ければ「判断待ち」に停めます。忘れられた未コミットの変更は、停める際に自動でブランチへ保存されます。
- **worker が落ちたときの再配布判断も同じ基準に。** 子リポに成果がある worker のカードは、別の worker に作り直させず「判断待ち」に置きます（成果の二重生産を防ぐ既存ルールを子リポにも適用）。

### Workers that deliver into a child repo now count as done

A project that is a parent folder bundling independent repos gets its deliverables in nested worktrees of the child repos. The engine only counted the parent branch, so a worker that had finished, committed, and declared done was nudged as a stall for ten minutes while its work sat unnoticed for 26 (measured 2026-09-13).

- **Commits in nested repos / linked worktrees count as work.** With the parent branch at 0, a commit one level under the worktree still promotes the card to review and reaches the commander.
- **The journal says where the work is** — "deliverables in nested repos .trending-wt / .figma-wt: 2 commits (parent branch 0)" — so the commander's first `git rev-list` on the parent does not read as "nothing to integrate".
- **A "done" with no commits anywhere is no longer a silent stall.** It is announced at first sight (bell + journal), held for 3 minutes without nudging (a "Continue." to a finished worker only makes it talk), then parked in "Needs decision". Forgotten uncommitted changes are saved onto the branch when it is parked.
- **Crash recovery uses the same definition of work:** a fallen worker with nested commits is parked, not re-dispatched to a fresh worker (the existing never-redo-visible-work rule, one level down).
