# 0.11.157

### 日本語

- **司令官が自分で出した質問に答えると、その答えがすぐ司令官に届くようになりました。** これまでは答えが記録されるだけで司令官に伝わらず、社長が重ねて伝えるまで司令官が止まったままになることがありました。司令官が手を離せないときは、届くまで1分おきに送り直します。司令官がいなければ起こしてから届けます。

---

### English

- **When you answer a question the commander raised itself, the answer now
  reaches the commander right away.** Previously the answer was only
  recorded, so the commander could sit waiting until the president passed it
  on by hand. If the commander is busy, the answer is re-sent every minute
  until it lands; if no commander is running, one is started first.
