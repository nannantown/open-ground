# 0.11.186

### 日本語

- **「再送」で同じ言葉が二重に送られることがなくなりました。** 送れなかった言葉の古い行を消せなかったときは、再送せずにその行を残します。
- 写真の付いた言葉で、その写真がもう残っていないときは、「再送」が押せない見た目になります(「削除」はこれまでどおり使えます)。
- iPhone と表示をそろえるための仕様書の直しも入っています。

---

### English

- **Resend no longer sends the same words twice.** If the old failed line
  cannot be removed, nothing is resent and the line stays as it is.
- When a line's photo is no longer kept, its Resend key shows as disabled
  (Delete still works).
- Also includes spec fixes that keep the iPhone and the Mac showing the same
  states.
