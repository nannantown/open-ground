## OPEN GROUND 0.11.116

### 日本語

プロジェクト上部を一行にまとめ、作業に使える画面を広げました。

- プロジェクト名、タブ、利用状況、移動操作をコンパクトな一行に配置しました。狭い画面ではタブを横にスクロールできます。
- プロジェクト名を押すと、説明、説明の生成、名前の変更、フォルダやエディタを開く操作、ブランチを確認できます。
- オーナー向けの表示切り替えとスキルも、プロジェクトの詳細にまとめました。利用できる機能や保存データは変わりません。
- 追加タブの再生状態を維持しながら、詳細画面を閉じた後のキーボード操作を改善しました。

---

### English

The project header now fits in one row, leaving more room for your work.

- Project name, tabs, usage and navigation share a compact row. Tabs scroll
  horizontally on narrow screens.
- Click the project name to access its description, description generation,
  rename, folder/editor actions and branches.
- Owner display controls and Skills are grouped in project details. Available
  features and saved data are unchanged.
- Keyboard focus after closing project details is improved while custom tabs
  retain their playback state.
