# 0.11.160

### 日本語

- **キー1つでエージェントチームのバーを開け閉めできるようになりました。** Mac は Cmd+J、Windows は Ctrl+Shift+J です。どのタブを見ていても、ターミナルに文字を打っている途中でも効きます(日本語の変換中は邪魔しません)。Windows の Ctrl+J は Claude の入力欄で改行に使われているため、1つずらしています。

---

### English

- **Open and fold the agent-team bar with one key.** Cmd+J on Mac,
  Ctrl+Shift+J on Windows. It works from any tab, even while you are typing
  in a terminal, and stays out of the way during Japanese input. On Windows
  plain Ctrl+J is left alone because Claude's prompt uses it for a new line.
