### English

- Control automatic operation from each normal Ground frame's header. Multiple frames can be ON; projects inside any ON frame are eligible, while outside projects stop taking new automatic work. Accepted work remains monitored and manual conversations stay available.
- Ground frame names and their editing fields now use the body font. Removed the separate automatic-frame toolbar button and the owner's project-level automatic start, stop and resume controls.
- Existing automatic-frame settings and layouts are preserved. Turning the last frame OFF keeps all new automatic work paused. Owner checks, revision checks, undo and delayed permission checks preserve the selected scope.
- Standardized macOS artifact names so update files and their blockmaps use matching download names.

### 日本語

- 通常のGroundフレームの見出しで、自動運用をオン・オフできるようにしました。複数の枠をオンにでき、オンの枠内を運用対象にします。枠外では新しい自動作業を停止し、受理済みの作業の監視と手動の会話は維持します。
- フレーム名と名前の編集欄をゴシック体に揃えました。左上の専用ボタンと、オーナー画面のプロジェクト別の自動運用・開始・再開ボタンを削除しました。
- 既存の自動運用設定と配置を引き継ぎます。最後の枠をオフにしても以前の運用設定へ戻らず、対象なしを維持します。権限確認、保存世代、取り消し操作、確認待ち中の切り替えでも対象範囲を保ちます。
- macOSの配布ファイルと更新用の補助ファイルの名前を揃えました。
