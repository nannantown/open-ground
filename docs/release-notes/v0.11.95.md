## OPEN GROUND 0.11.95

### ペルソナを「使いたい人だけ」オンにできるように

これまで owner だけだったペルソナを、**全ユーザーが自分でオンにできる opt-in(試験運用)** にしました(オーナー判断, 2026-08-20)。Swarm と同じく、オンにする前に何が起きるかを正直に伝える注意書きを出します。

- **ペルソナ(試験運用)トグル** — 設定 → 詳細 に追加。オンにすると Ground のペルソナ画面が現れます。既定はオフ。**全プラットフォーム**(ペルソナの1ターンは隔離スクラッチ内の制限付き Claude 実行で、Swarm のような常駐ワーカーもガード依存もないため)。
- **正直な注意書き** — オンにする前に開示: すべてこのパソコンの中だけに保存されます(あなた自身のコーパスで外には出ません)/ 1ターンごとにあなた自身の Claude サブスクを使います / 1ターンは許可確認をスキップした Claude を隔離スクラッチの中で実行します / サポート対象外。
- **Swarm との結合を是正** — 0.11.94 の副作用で、macOS で Swarm を opt-in にすると(any-of ゲート経由で)ペルソナ画面まで出ていました。ペルソナのゲートを独立させ、**Swarm の opt-in はもうペルソナを開きません**(オーナー自身の「Swarm を入れたらペルソナも見える」結合はサーバ側に移設して維持)。データ漏洩はありませんでした(ループバック・自分の空コーパスのみ)。

**変わらないこと**: sandbox は引き続き owner 限定。owner の実験トグルはそのまま。

### Turn Persona on if you want it

Persona was owner-only; now **any user can opt in** to it themselves — behind an honest "still being tuned" warning, the same shape as the Swarm opt-in (owner decision, 2026-08-20).

- **Persona (experimental) toggle** — in Settings → Advanced. Turning it on reveals the Persona screen on Ground. Off by default. **All platforms** (a persona turn is a locked-down scratch-session Claude run — no standing workers, no guard dependency, unlike Swarm).
- **Honest warning** — before you turn it on: everything stays on this machine (your own corpus, never shared); each turn spends your own Claude subscription; a turn runs Claude with tool-permission prompts skipped, inside a locked-down scratch session; not covered by support.
- **Swarm coupling fixed** — a 0.11.94 side effect meant that turning on the Swarm opt-in (macOS) also revealed the Persona screen via the old any-of gate. Persona's gate is now independent, so **the Swarm opt-in no longer opens Persona** (the owner's own "Swarm on ⇒ Persona visible" coupling is preserved, moved server-side). No data was ever exposed (loopback, your own empty corpus).

**Unchanged:** sandbox stays owner-only; the owner experiment toggles are untouched.
