### English

- Explicit tool rejections from OPEN GROUND guards are now recorded before the app processes the matching Claude SDK result. These rejected calls no longer remain marked as running when Claude Code omits a post hook. The guard still denies the command; it does not grant permission or retry it.
- Other failures, background commands and interrupted or unconfirmed effects remain held for inspection. Subscription-only authentication and billing settings are unchanged.

### 日本語

- OPEN GROUNDのガードが実行前に明示的に拒否した操作について、対応するClaude SDKの結果をアプリが処理する前に拒否結果を保存するようにしました。Claude Codeから終了フックが届かない場合も、拒否済みの操作が「実行中」のまま残りません。権限を許可したり、コマンドを再実行したりはしません。
- それ以外のエラー、バックグラウンド実行、中断・結果不明の操作は引き続き確認待ちにします。契約ログインと従量課金APIを使わない設定は維持しています。
