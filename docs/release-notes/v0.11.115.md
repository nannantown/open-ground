## OPEN GROUND 0.11.115

### 日本語

日常の作業画面を整理し、一般ユーザー向けの機能とオーナー向けの実験機能を分けました。

- 一般ユーザーの画面は、プロジェクト管理・ボード・ターミナル・任意で有効にするSwarmが中心になります。macOSのSwarmオン・オフは引き続き利用できます。
- プロジェクト内のCanvas、Research、追加タブ、WordPress連携などはオーナー向け表示にまとめました。既存の設定や保存データは削除しません。
- オーナーは一般ユーザー向けの表示へ切り替えて確認できます。表示を切り替えてもアカウントや実行中の作業は変わりません。
- Personaによる代理判断、追加タブのマーケット・投稿・審査、使われていない自動処理を撤去しました。手元にあるPersonaデータや追加タブは残ります。
- 「説明を生成」の結果が、遅れて届く読み込み結果で消える問題を修正しました。
- ボードの難易度指定を作業の振り分けに反映し、常駐AIの文脈量に上限を設けました。Swarm利用時には重複する手動実行設定を隠します。
- Swarmの司令官の実行方式を統一し、方式を選ぶ設定をなくしました。停止・再開・会話履歴は維持します。補給官と通常のターミナルの使い方は変わりません。
- 人間への確認、停止・復旧、バックアップ、利用上限の検知は引き続き利用できます。WindowsでのSwarm公開範囲は変更していません。

### English

This release simplifies the everyday workspace and separates public features
from owner-only experiments.

- Public views focus on project management, Board, Terminal and optional Swarm.
  The existing macOS Swarm opt-in remains available.
- Project Canvas, Research, custom tabs and WordPress controls remain in the
  owner view. Existing settings and saved data are preserved.
- Owners can preview the public view without changing identity or running work.
- Persona proxy decisions, custom-tab marketplace/submission/review flows and
  dormant automation have been removed. Local Persona data and installed custom
  tabs are retained.
- Generated project descriptions no longer disappear when an older read arrives.
- Card difficulty now informs dispatch, resident desks have context limits, and
  duplicate manual-run defaults are hidden while Swarm is enabled.
- New Swarm commanders use one execution path, without a runtime selector.
  Stop, resume and conversation history remain supported. Supply and ordinary
  terminals retain their existing behavior.
- Human confirmation, stop/recovery, backups and usage-limit detection remain.
  Windows Swarm availability has not been expanded.
