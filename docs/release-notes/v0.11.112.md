## OPEN GROUND 0.11.112

### いちばん希少なモデル枠を、本当に必要な席だけに残します

Swarm（複数の作業者を同時に走らせる機能）では、作業者・司令官・監督・補給官・レビュー班といった複数の「席」が、それぞれ Claude を起動します。これまで、モデルの割り当て表に**そもそも載っていない席**があり、そこは実行モードを一切見ずに最上位モデルを指定していました。

- **最上位モデルを希望するのは「重い設計カードを担当する作業者」だけになりました。** 司令官・監督・補給官・レビュー班は実行モードに従います（「最大出力」モードを選んだときは、従来どおり全席が最上位モデルです）。
- **席を新しく足した人がモデル指定を忘れると、ビルドが止まります。** これまでは、忘れると「いちばん希少なモデルが黙って選ばれる」作りでした。沈黙して漏れるのではなく、その場でエラーになります。
- **⚠ これは今の消費量を減らす変更ではありません。** 表から漏れていたレビュー班は現状どこからも呼ばれておらず、消費はもともとゼロでした。週次の消費を実際に動かしているのは「重いカード」の判定条件のほうで、そこは今回は変更していません（`docs/commander/04-quota-models.md` §5.9 に実測を記載）。

---

### The scarcest model tier is now reserved for the one seat that needs it

In Swarm, several seats each launch their own `claude`: the worker, the commander, the overseer, the supply officer, and the adversarial review panel. One of those seats **was not in the model matrix at all** — it named the top tier directly and never consulted the execution mode.

- **Only one slot still desires the top tier: a worker on a heavy design card.** Commander, overseer, supply and the review panel now follow the execution mode (an explicit "max" run still puts every seat on the top tier, as before).
- **Forgetting to resolve the model now fails the build.** It used to mean "silently get the scarcest tier" — an omission that produced no error and no log. That omission is now a type error instead.
- **⚠ This does not reduce today's usage.** The review panel that was leaking has had no production caller since 2026-07-15, so it was spending nothing. The measured driver of the weekly top-tier usage is the heavy-card classifier, which this release deliberately does not touch (see `docs/commander/04-quota-models.md` §5.9).
