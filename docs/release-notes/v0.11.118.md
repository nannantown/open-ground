## OPEN GROUND 0.11.118

### ローカルのカスタムタブでマイクが使えます

ローカルに入れたカスタムタブは、これまで中身を隔離するために「素性の分からない枠」で表示していました。その枠はマイクの許可を要求できないので、**タブの中で録音する**ことができませんでした。

- **`localApp` を宣言したローカルタブだけ**が、自分専用の固定アドレスで開き、マイクの許可を受け取れるようになりました（手元の Songs タブがこれに当たります）。
- **それ以外のカスタムタブは今までと同じ隔離枠のまま**です。マイクの制限を回避するために枠やブラウザの安全装置を緩める、という直し方はしていません。
- **ロックダウン中はこの特別枠も無効**になります。

### カスタムタブの右端にあったターミナルの引き出しを撤去

カスタムタブの右端から引き出せたターミナルは、通常の Terminal タブと Swarm タブがあれば要らないものでした。**Terminal と Swarm はこれまでどおり**です。

---

### Local custom tabs can use the microphone

A locally installed custom tab used to render only inside an opaque sandbox frame, which cannot request microphone permission — so nothing inside a tab could record. Now a tab that declares `localApp` opens at its own fixed loopback origin with microphone delegation (this is what the local Songs tab needs). **Every other custom tab keeps the opaque sandbox frame**, and the microphone restriction is never worked around by relaxing iframe or browser security globally. The special frame is disabled under lockdown.

### The right-edge terminal drawer is gone from custom tabs

The drawer duplicated the ordinary Terminal and Swarm tabs, which are unchanged.
