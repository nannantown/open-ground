# 0.11.142

## 「全員止まった」の知らせが、固まった作業でも必ず届くようになりました

**実現されること**

- **担当が固まったまま動かなくなったときも、「全員止まった」の知らせが届くようになりました。** これまでは、途中で固まった作業が「作業中」に見え続け、知らせが鳴らないことがありました。
- **作業場所で文字を出し続けるだけの画面(開発用サーバーなど)があっても、それを「作業中」とは数えなくなりました。** 本当に誰も進めていないときは、ちゃんと知らせが出ます。

---

## The "everyone stopped" alarm now reaches you even when work is stuck

- **When a worker freezes and stops moving, the "all workers stopped" alarm
  now fires.** Before, a frozen task could keep looking "in progress" and the
  alarm stayed silent.
- **A screen in the work folder that only keeps printing (such as a
  development server) no longer counts as someone working**, so the alarm
  fires when nobody is really moving the work forward.
