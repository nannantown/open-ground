# 0.11.189

### 日本語

- **アシスタントの入力欄にスクリーンショットを貼り付けられるようになりました。** クリップボードの画像を Cmd+V で貼ると、写真ボタンで選んだときと同じ小さいサムネイルが出て、そのまま送れます。
- 文字だけの貼り付けはこれまでどおりです。Excel や Word から文字と一緒に画像が貼られた場合も、文字は入力欄に残ります。

---

### English

- **You can paste a screenshot into the assistant's input.** Press Cmd+V
  with an image on the clipboard and the same small thumbnail as the photo
  button appears above the input, ready to send.
- Pasting text works as before. When text comes with a picture (Excel,
  Word), the words still land in the input.
