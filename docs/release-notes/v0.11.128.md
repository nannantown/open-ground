# 0.11.128

## 司令官の席は名札だけに — Swarm 画面の整理が完了

**実現されること**

- 司令官の席は **名札のような小さな表示** になりました。見えるのは「動いている/止まっている/いない」と、控えめな起動・停止ボタンだけです。
- Swarm で使われていなかった表示(司令官の細かい計器・着地のグラフ・古い文言など)を取り除きました。画面に残っているのは、誰が何をしていて、止まっていないかだけです。
- 見張り(監督)のオン・オフは、画面上部の帯に移りました。
- 1週間に本体へ入った数を知りたいときは、**社長に聞けば答えてくれます**(グラフの画面はなくなりました)。
- 高リスクで保留した変更は、社長に「マージして」と伝えれば入ります。

**内容**

Swarm 画面の整理(1: 監督タブをなくす → 2: 1画面に並べる → 3: 司令官の表示を小さくする)の最後の1枚です。残す・消すの判断は「オーナーが見る必要があるか」「今の運用(社長が窓口)で使われているか」で決め、一覧表を `docs/commander/SIMPLIFICATION.md` に残しました。消したのは画面の表示だけで、保存済みのデータやアプリ内部の機能はそのままです。

やらないこと: 一般ユーザー(Swarm を自分でオンにした人)の画面の動きは変えていません。

## The commander's seat is now just a nameplate — Swarm clean-up done

- The commander's seat is now **a small nameplate**: whether it is running,
  stopped or absent, plus a discreet start/stop button.
- Swarm displays nobody used (the commander's detailed gauges, the landed
  chart, stale strings) are gone. What stays is who is doing what, and whether
  anything is stuck.
- The Monitoring on/off switch moved to the top bar.
- For how much landed this week, **ask the president** — the chart is gone.
- A high-risk change on hold goes in when you tell the president "merge it".

**Why.** This is the last of the three Swarm clean-up cards (remove the
Overseer tab → one screen → shrink the commander). Each keep-or-remove call was
made on "does the owner need to see it, and is it used now that the president
is the front desk"; the table is in `docs/commander/SIMPLIFICATION.md`. Only
displays were removed — saved data and the app's internals are untouched.

Not in this release: nothing changes for public users who switched Swarm on
themselves.
