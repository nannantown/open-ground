# 0.11.155

## 状態の色と印がアプリ全体でそろいました

- **完了は緑のチェック、動いているは青、指示待ちは黄の挙手**。Ground のカード、プロジェクト検索の一覧、エージェントチームの帯、席のアイコンと名札、Board のどこを見ても同じ色と印で出ます。
- **完了の印は「目」から緑のチェックに変わりました。** 仕上がって見てほしいときに出る印です。点く・消えるタイミングは今までと同じです。
- 質問がある席は薄くならず、角に黄色のランプが点きます。
- 明るい画面・暗い画面のどちらでも見分けられる色にしています。

---

## One set of state colours across the app

- **Done is a green check, running is blue, waiting for you is a yellow
  raised hand** — the same on Ground cards, the project search list, the
  Agent Team bar, seat icons and nameplates, and the Board.
- **The "done" mark changed from an eye to a green check.** It still appears
  and clears at the same moments as before.
- A seat with a question is no longer faded and shows a yellow corner lamp.
- The colours are tuned to be told apart in both the light and dark themes.
