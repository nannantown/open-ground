# 0.11.143

## 画面一番下のバーがすっきりしました — 名前は「エージェントチーム」に

**実現されること**

- **バーのどこをクリックしても開け閉めできるようになりました。** 左の小さなボタンを狙わなくても、行の空いているところを押せば開閉します(オン/オフのスイッチを押したときは開閉しません)。
- **名前が「Swarm」から「エージェントチーム」(英語表示は Agent Team)に変わりました。**
- **「状況の監視」「最適化」の切り替えをバーから外しました。** 動きは今までどおりです。変えたいときは社長に言葉で頼めば切り替えてくれます。再起動で状況の監視がオフに戻ったときは、社長がひとことお知らせします。
- **「稼働中ワーカー」「再起動後に自動再開」の表示をバーから外しました。** 使えるモデルの設定は設定画面に移りました。

## A tidier bottom bar — now called "Agent Team"

- **Click anywhere on the bar to open or fold it.** No need to aim for the
  small button on the left; the on/off switch still only switches.
- **"Swarm" is renamed "Agent Team"** (エージェントチーム in Japanese).
- **The "monitoring" and "optimize" controls are gone from the bar.** Nothing
  changes in how it runs — ask the president in plain words to switch them.
  If a restart turned monitoring off, the president tells you.
- **The "workers running" and "auto-resume after restart" chips are gone.**
  The usable-models setting now lives in Settings.
