# 0.11.173

### 日本語

- **放っておいたときに重くならなくなりました。** 何も頼んでいないときのサーバーの負荷がおよそ 30% から 3% に下がり、画面を見ていない間は画面と GPU もほぼ休みます。見ていない間は動きが止まりますが、作業中・質問待ち・完了の色はそのまま読めます。
- **Mac のアシスタントに「電話モード」と「チャットモード」ができました。** 電話モードでは声で話すと声で返事が来て、スピーカー・消音・終了を切り替えられます。チャットモードではマイクを押して話すと、入力欄に文字で入ります。オーディオインターフェースが既定の入力になっていると声が入らなかった問題も直しました。
- **アシスタントの小窓から写真を送れるようになりました。** 送る前に小さく表示され、取り消しもできます。
- **社長の席の通話記録を Mac から消せるようになりました。** 今日以外の通話には日付が付き、表示言語を切り替えると「通話 / Call」も切り替わります。

---

### English

- **OPEN GROUND no longer stays busy when left alone.** With nothing asked of
  it, the server drops from about 30% to about 3% of a core, and the screen
  and GPU rest while nobody is looking. Motion pauses while you are away, but
  the working / waiting / done colours still read the same.
- **The Mac assistant now has a call mode and a chat mode.** In call mode you
  talk and it answers by voice, with speaker, mute and end controls. In chat
  mode the mic button types what you say into the input. Dictation that heard
  nothing when an audio interface was the default input is fixed.
- **You can send a photo from the assistant window,** with a preview you can
  remove before sending.
- **The president's call records can be cleared from the Mac.** Calls from
  other days show their date, and "Call / 通話" follows the display language.
