# 0.11.194

### 日本語

- **オーナーアカウントで ChatGPT を選べるようになりました。** アシスタントと自動作業のそれぞれで、Claude と ChatGPT を選択できます。ChatGPT の接続・実行は、OPEN GROUND にオーナーとしてログインしたアカウントだけが利用できます。自動作業の ChatGPT 対応は現在 macOS 専用です。
- **ChatGPT プランの利用枠で動作します。** API キーの設定や従量課金 API への自動切り替えはありません。認証や利用上限のエラーが起きたら停止し、別の課金経路で続行しません。接続時の ID トークン形式、ツール実行を含む応答の受信、終了・更新時の実行プロセスの回収も修正しました。
- アシスタントの利用権限を確認してから履歴を取得するようにし、ログアウト状態の起動時に不要な権限エラーが出ないようにしました。

---

### English

- **Owner accounts can now choose ChatGPT.** Select Claude or ChatGPT independently for the assistant and automatic work. Connecting and running ChatGPT requires a signed-in OPEN GROUND owner account. ChatGPT automatic work currently supports macOS.
- **Runs within the connected ChatGPT plan allowance.** There is no API-key setup or automatic fallback to metered API billing. Authentication and usage-limit errors stop the operation instead of changing its billing route. This release also fixes ID-token format handling, streamed tool-call assembly, and child-process cleanup when quitting or updating the app.
- Assistant history now loads after access is confirmed, avoiding unnecessary permission errors when starting a signed-out install.
