### English

- A notice from the app now reaches the president's window once. Before, two deliveries could type the same notice into the input box, and it could stay there unsent.
- A long notice is now always sent, even when Claude Code scrolls its input box.
- Subscription login remains in use. Metered inference APIs and API-key fallbacks remain disabled.

### 日本語

- アプリから社長の窓口への知らせが、1回だけ届くようになりました。これまでは、同じ知らせが入力欄に二重に打ち込まれ、送信されないまま残ることがありました。
- 長い知らせも、入力欄がスクロールする場合も含めて、最後まで送信されるようになりました。
- 契約ログインを維持し、従量課金のAI API・APIキーへの切り替えは無効のままです。
