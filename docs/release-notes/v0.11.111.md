## OPEN GROUND 0.11.111

### 更新が入らなかったとき、理由が残るようになります

「今すぐ再起動」を押してアプリが終了したのに、起動すると前の版のまま — そのとき何が起きたかを知る手段が、これまでありませんでした（アプリ側の記録はどこにも書かれず、macOS 側の記録にも何も残っていない、という状態）。

- **更新まわりの記録がファイルに残ります。**`~/.openground/updater.log`。アプリ自身の記録に加えて、更新ライブラリの内部の記録、macOS のインストーラのエラーも同じファイルに入ります。
- **入らなかったら、次の起動でそう言います。**終了する前に「これから X に入れ替える」と控えておき、起動時にバージョンが変わっていなければ「X は入りませんでした」と表示します（記録の末尾つき、「ログを開く」ボタンつき）。同じ「ダウンロードしました」の画面がまた出るだけ、という状態は終わりです。
- **ダウンロード済みの更新を、1 時間後に見失わなくなります。**1 時間ごとの確認で同じ版を見つけ直したとき、「準備済み」の印を消してしまう作りになっていました。その状態で「今すぐ再起動」を押すと、準備が終わっているのに待たされていました。

### When an update does not land, the reason is now on disk

"Restart now" → the app quits → it comes back on the old version, and until now there was no way to know why: the app wrote nothing, and the OS installer's own log had no entry either.

- **Every updater line is written to a file** — `~/.openground/updater.log` — including the update library's internal narrative and the OS installer's errors.
- **A failed install is announced on the next boot.** Before quitting, the app notes "installing X"; if it wakes up on the old version it says "X was not installed", with the log's tail and an "Open log" button — instead of the same "downloaded" dialog again.
- **A downloaded update is no longer forgotten after an hour.** The hourly re-check of the same version used to clear the "staged" flag, so "Restart now" waited on preparation that was already done.
