# 0.11.154

## エージェントチームの席は名札のクリックで閉じます

- **マネージャーとワーカーの席は、名札のどこをクリックしても閉じて**右端のアイコン列に戻ります。アイコンをクリックすると開き、名札をクリックすると閉じる、の対になりました。
- **社長の名札はクリックしても何も起きません。** 社長の席はいつも出ています。
- 名札の中のボタン(停止など)は今まで通り効き、押しても席は閉じません。
- 席を大きく広げるのは、席と席の境目のクリックだけになりました。幅のドラッグは今まで通りです。

---

## Agent Team seats close from their nameplate

- **A click anywhere on a manager or worker seat's nameplate folds the seat**
  back onto the icon rail at the right edge — the icon opens a seat, its
  nameplate closes it.
- **A click on the president's nameplate does nothing**; that seat is always
  shown.
- Buttons inside a nameplate (stop, etc.) still work and never close the seat.
- Widening a seat is now done only by clicking the border between seats;
  dragging to resize works as before.
