## OPEN GROUND 0.11.113

### 「Running」は、本当に動いているときだけ出ます

Ground 画面のプロジェクトカードに、何も動いていないのに「Running」が出続けることがありました。実際の報告では、worker の最後の動きから3時間以上たっても表示が消えず、「なぜ Running になっているのか」を2回確かめることになっていました。

- **作業を終えて統合待ちの worker は、もう「Running」に数えません。** 作業が終わった worker は、統合されるまでセッションが残ります。これまでは「セッションが残っている＝動いている」と判定していたため、何も進んでいないカードに「Running」が出ていました。今は、worker が実際に作業中のときだけ数えます。
- **終了済みのセッションを「生きている」と扱わなくなりました。** worker の一覧は、セッションが実在するときだけ、その worker に連絡できる状態として表示します。
- **本当に作業中の worker は、これまでどおり「Running」になります。** 質問で止まっている worker は、カードの「質問あり」として見えます。
- 利用上限で一時停止している worker のカードは、「Running」ではなく表示なしになります（一時停止は Swarm タブと通知で確認できます）。

### "Running" now means something is actually running

A project card on the Ground screen could keep showing "Running" when nothing was moving. In the reported case the stamp stayed up more than three hours after the last worker activity, and the owner had to ask twice why it said Running.

- **A worker that has finished and is waiting to be merged no longer counts as Running.** A finished worker's session stays open until it is integrated, and the old check treated an open session as activity — so an idle card said Running. The lamp now counts a worker only while it is actually mid-task.
- **A session that has ended is no longer reported as alive.** The worker list only offers a worker as reachable while its session really exists.
- **A worker that is genuinely working still shows Running**, and a worker waiting on a question shows up as an open question on the card.
- A worker paused at a usage limit now leaves the card blank instead of Running; the pause is still shown in the Swarm tab and in notifications.
