## OPEN GROUND 0.11.96

### 共有(コラボ)は、出荷版でも既定オフになりました

これまで出荷ビルドには共有機能が**最初からオン**で焼き込まれていました。その状態でサインインすると、**プロジェクトの Board か Canvas タブを開いただけで**、そのプロジェクトの内容が運営者のクラウドに載ります — 「共有する」操作は不要で、消す手段もありませんでした(オーナー判断, 2026-08-23)。

- **既定オフ化** — リリース工程から既定値を削除。以後、共有機能が乗るのは設定を明示したビルドだけです。設定が無ければアプリは共有関連のコードを一切読み込みません。**ログインは今まで通り使えます**(共有とは独立です)。
- **戻り防止** — 既定オンが復活したらテストが赤くなります(4通りの戻し方を実際に試して確認済み)。

**まだ残っていること**: すでにクラウドに載っている分は消えません(削除経路が存在しないため)。既存インストールは、この版に更新するまで従来の挙動のままです。

### タスクカードが読めるようになりました

ワーカーが動いているカードは5段の情報が積まれていて、下3段が毎回途中で切れていました(本文の頭、ブランチ名、報告文)。

- **切れる3段を外しました** — カードはタイトル・状態・優先度だけに。タイトルは元々切れていないので、そのまま残ります。
- **状態は「稼働中 · verify」の形** — 短い決まった語だけなので切れません。
- **消えた情報は失われていません** — ブランチ名と報告文はカードにカーソルを乗せると出ますし、Swarm タブには今まで通り全文があります。

### ペルソナが、あなたの返事を読むようになりました

2回目以降の返事が1回目の丸写しになっていました。原因は、会話を再開したときに AI が**それまでのやりとりを画面に出し直す**こと。アプリはそれを「新しい答え」と誤認し、あなたが書いた文を読む前に打ち切っていました。

- **その回だけの通し番号** — 今回の答えだけを受け取り、再表示された過去の答えは無視します。番号が返らなかった回は正直に失敗し、次の回で仕切り直します。
- **直近のやりとりを毎回伝える** — 会話の続きが AI の記憶頼みにならないようにしました。「もう答えてもらったことを聞き直さない」も明示しています。

### Collab now ships off by default

Release builds baked the sharing feature **on**. Signed in, that meant **merely opening a project's Board or Canvas tab** put that project's contents on the operator's cloud — no share action, and no way to delete the copy (owner decision, 2026-08-23).

- **Off by default** — the fallback is gone from the release pipeline. Sharing now ships only in a build that configures it explicitly; without that, the app never even loads the collab code. **Sign-in is unaffected** — it never depended on collab.
- **It cannot come back quietly** — a guard test fails if the default returns (four ways of reintroducing it were measured red).

**Still open:** what is already in the cloud is not removed (there is no delete path yet), and existing installs keep the old behaviour until they update.

### Task cards you can actually read

A card with a worker on it stacked five blocks in the width of a card, and three of them were cut off every time (the body's opening, the branch handle, the worker's report).

- **The three that truncated are gone** — a card is title, state, priority. The title was never the problem, so it stays.
- **State reads as "稼働中 · verify"** — short fixed words, so nothing is cut.
- **Nothing was lost** — branch and report are on hover, and in full in the Swarm tab.

### Persona now reads what you said

Every reply after the first repeated the first one. When a conversation resumes, the AI re-prints the exchange so far; the app mistook that for a new answer and stopped before reading your actual message.

- **A per-turn token** — only this turn's answer is accepted; a replayed one is ignored. A turn whose token never returns fails honestly and the next one starts fresh.
- **Recent exchanges are stated every time** — continuity no longer rests on the AI remembering, and it is told not to re-ask what you already answered.
