# 0.11.170

### 日本語

- **画面に浮いているアシスタントに声で話しかけられるようになりました(試験中)。** 入力欄の横のマイクを押すと聞き取りが始まり、もう一度押すと止まります。声で話したときは、返事も声で読み上げます。文字はいつでも打てます。聞き取りと読み上げは Mac に入っている機能を使うので、追加の費用はかかりません。初めて使うときは、Mac がマイクと音声認識の許可を求めてきます。
- 入力欄が空のときは、薄い字で「話しかける…」と表示します。
- 今までのやりとりは、広げたときだけ表示するようにしました。広げたか畳んだかは覚えておきます。

---

### English

- **You can now talk to the floating assistant by voice (in testing).** Press
  the mic next to the input to start listening, and press it again to stop.
  When you speak, the reply is read aloud too. You can type at any time.
  Listening and reading aloud use what is built into your Mac, at no extra
  cost. The first time, macOS asks for microphone and speech-recognition
  permission.
- An empty input now shows a faint "Say something…".
- Past messages are shown only when you expand the window, and it remembers
  whether you left it expanded.
