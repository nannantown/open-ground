# 0.11.120

## 使用量の内訳に「実数」が出ます

**実現されること**

- 使用量のパネルの内訳が、**割合(%)だけでなくトークンの実数**も出します(例: `340k · 30%`)。
- これで、**ターミナルを使わずに燃料を測れます。**やり方は「数字を控える → カードを流す → もう一度控える → 引き算」だけです。
- 直前の版で入れた worker の試験スイッチ(設定 → 詳細設定)の効果を、この引き算で確認できます。

**内容**

これまで内訳は割合だけでした。**割合は引き算できません。**「先週 30%、今週 30%」では、その間に何を使ったのか分かりません。そのため「効果を測る」と言いながら、ターミナルで `npm run swarm:audit` を打つ手順しか用意できていませんでした。

ターミナルを開かせないための道具でターミナルを開かせていたので、そこを直しました。オーナーの指摘によるものです。

やらないこと: 1 枚ごとの燃料表示は、この版には入れていません(カードと claude セッションの紐付けは既にあるので、必要になれば別カードで)。

## The usage breakdown now shows the NUMBER, not only the share

- Each row of the 7-day breakdown carries its token count next to the share
  (e.g. `340k · 30%`).
- That makes fuel measurable **without a terminal**: note the number, run cards,
  note it again, subtract.
- It is what the worker-trial switch added in 0.11.119 needs in order to be
  judged at all.

**Why.** A share cannot be subtracted. "30% last week, 30% this week" says
nothing about what was spent in between, so the only measurement this panel
supported was `npm run swarm:audit` in a terminal — inside an app that exists so
you do not need one. The owner pushed back on that; this is the fix.

Not in this release: per-card fuel. The card-to-session link already exists in
the roster, so it is a separate card if it is wanted.
