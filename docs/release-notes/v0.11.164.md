# 0.11.164

### 日本語

- **iPhone の画面がロック中でも、社長窓口の知らせで iPhone を起こせるようになりました(試験中・まだ一部の利用者のみ)。** Apple のトランシーバー型の仕組み(Push to Talk)を使い、知らせが来るとロック中の iPhone が起きて、イヤホンで聞けるようにする Mac 側の準備です。使うには、Apple のサイトで通知用の鍵を作り、設定の「iPhone」に1回入れます。鍵は Mac の外に出ません。
- Apple に通知を断られ続けているときは、設定画面に「呼び出せていない」ことと、鍵の問題か iPhone アプリ側の問題かが表示されます。
- 業務モードが ON の間は、通知も送りません。

---

### English

- **The president desk can now wake a locked iPhone (in testing, not yet
  available to everyone).** Using Apple's Push to Talk, a notice wakes the
  locked iPhone so it can be heard on earphones; this is the Mac side of it.
  To use it, create a notification key on Apple's site and enter it once in
  Settings › iPhone. The key never leaves the Mac.
- If Apple keeps refusing the notifications, Settings says the wake is not
  working and whether the key or the iPhone app is at fault.
- While work mode is on, no notification is sent.
