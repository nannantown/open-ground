### English

- Fixed a Claude SDK input comparison that could treat reordered JSON object keys as different tool arguments. A confirmed guard rejection could otherwise remain unconfirmed and prevent the manager from starting. Array order, argument values, actor identity and durable receipt checks remain enforced.
- Managers now check existing recovery holds before choosing or recording a conversation. A refused launch returns its reason immediately and preserves the previous conversation pointer. Subscription login and the policy against metered inference APIs are unchanged.

### 日本語

- Claude SDKの入力項目の並び順が変わっただけで、同じ操作を別の入力と誤判定する不具合を修正しました。拒否済みの操作が確認待ちとして残り、マネージャーの起動を止める問題を防ぎます。値・配列の順序・担当の識別・記録の保存確認は引き続き照合します。
- マネージャーは会話を選択・保存する前に、既存の確認待ちを検査します。起動できない場合は理由を返し、以前の会話の参照を保持します。契約ログインと、従量課金のAI APIを使わない方針は維持しています。
