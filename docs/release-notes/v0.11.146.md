# 0.11.146

## エージェントチームがすっきり・知らせが短く・社長の稼働が一覧で分かるように

**実現されること**

- **司令官と作業係の席が、細い縦長の帯に畳まれるようになりました。** 最初は畳んだ状態で、動いている間だけ帯の印が光ります。帯を押すと開き、もう一度押すと畳みます。空いた幅は社長の席が広く使います。開け閉めはプロジェクトごとに覚えます。
- **他のプロジェクトの知らせは1行だけになりました。** 「〇〇で質問が来ています」のように短く届き、社長もその1行で伝えます。いま開いているプロジェクトの知らせは今までどおり詳しく届きます。
- **社長が動いている間は、一覧(Ground)のプロジェクトカードに running が出ます。** 社長が返事を作ったり調べたりしている最中だけ光り、待ち受けで止まっているときは出ません。

---

## A tidier Agent Team, shorter notices, and the president's activity on Ground

- **The manager and worker seats now fold into thin vertical strips.** They
  start folded; a strip's light glows only while that seat is working. Click
  a strip to open it, again to fold it. The president's seat gets the freed
  width. Open/folded is remembered per project.
- **Notices about other projects are now one line**, e.g. "Kickstand has a
  question for you". The project you are in still gets the full notice.
- **While the president is working, the project's Ground card shows
  running.** It lights only while the president is actually replying or
  researching, not while it is idle.
