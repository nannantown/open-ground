# 0.11.161

### 日本語

- **キー1つでプロジェクトの画面から Ground に戻れるようになりました。** Mac は Cmd+[(Finder やブラウザの「戻る」と同じ)、Windows は Ctrl+Shift+[ です。Board・Terminal・Canvas のどこにいても、ターミナルに文字を打っている途中でも効きます。Cmd+G は Canvas の「グループ化」で使われているため、このキーにしました。
- **カードのメモを書いた直後にプロジェクトを離れても、書いた内容が消えなくなりました。** これまでは戻るボタンで離れた場合も、保存される前に画面が閉じて内容が失われることがありました。

---

### English

- **Go back to Ground from a project with one key.** Cmd+[ on Mac (the same
  "Back" key as Finder and browsers), Ctrl+Shift+[ on Windows. It works from
  Board, Terminal and Canvas, even while typing in a terminal. Cmd+G was not
  used because the Canvas already uses it for Group.
- **A card note you just typed is no longer lost when you leave the project.**
  Previously, leaving (even with the back button) could close the screen
  before the note was saved.
