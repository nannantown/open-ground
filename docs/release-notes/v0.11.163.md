# 0.11.163

### 日本語

- **プロジェクトの上の帯が変わりました。** プロジェクト名は押しても何も開かない、ただの文字になりました。名前のすぐ横に「フォルダを開く」「エディタで開く(選択メニュー付き)」「ブランチ切替」が常に並びます。
- これまで名前を押して開いていた「プロジェクトの詳細」画面は無くなりました。名前の変更・説明の生成・スキルは、右の「…」メニューから使えます。説明文は名前にマウスを乗せると表示されます。
- 窓が狭いときは、フォルダ・エディタ・ブランチも「…」の中から同じように使えます。メニューを開いて Esc を押すと、メニューだけが閉じます。

---

### English

- **The project header changed.** The project name is now plain text and
  opens nothing when clicked. Open folder, Open in editor (with its chooser)
  and the branch switcher always sit right next to it.
- The "Project details" dialog is gone. Rename, Generate description and
  Skills are in the "…" menu on the right; the description shows when you
  hover the name.
- In a narrow window, folder, editor and branch are reachable from "…" as
  well. Escape with a menu open closes just that menu.
