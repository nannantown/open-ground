# 0.11.135

## Canvas の付箋や文字が、ライトでもダークでも読めるように

**実現されること**

- **Canvas の付箋・テキストの文字色が、後ろに描かれているもの(付箋の色・枠の塗り・図形・見本の画面など)に合わせて、自動で読める色になります。** ライトでもダークでも同じように読めます。これまでは、ダークにすると淡い付箋の上に淡い文字、暗い背景に暗い見出し、といった読めない組み合わせになっていました。
- 自分で文字色を選んだ場合はその色を使います。そのうえで、ライトかダークのどちらかで読みにくくなる組み合わせだと、右の設定欄で知らせます。
- AI に Canvas の図を作らせたときも、図形やグラデーションの上の文字が読める色になります。
- (Swarm) アプリが強制終了したあと、生き残っていた担当と新しい担当が同じ作業場所で二重に動くことがないよう、生き残りが終わるまで作業の回収を待つようにしました。

## Canvas stickies and text stay readable in light and dark

- **The text colour of Canvas stickies and text now follows whatever is painted
  behind it** (the sticky's colour, a frame's fill, a shape, a mock screen), so
  it reads in both the light and the dark theme. Dark mode used to show pale
  text on pale stickies and dark headings on the dark canvas.
- A text colour you pick yourself is kept; the inspector warns you when that
  colour is hard to read in either theme.
- Designs the AI draws on a Canvas get readable text over shapes and gradients
  too.
- (Swarm) After a hard crash, the app now waits for a surviving worker to finish
  before reclaiming its card, so two workers never edit the same worktree.
