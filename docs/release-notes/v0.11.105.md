## OPEN GROUND 0.11.105

### 「ブログの下書きを開く」が正しい編集画面を開きます

WordPress 本体をサブフォルダ（例: `/wp`）に置いているサイトで、下書きは正しく作られているのに、リンクを押すと「ページが見つかりませんでした」になっていました。

- **リンク先を WordPress 本人に聞くようにしました。** 表向きのアドレスに `/wp-admin` をつなぐのではなく、サイトが申告する管理画面の場所を使います。
- **すでに投稿済みのレポートのリンクも直ります。** 次回の同期で自動的に付け替わるので、押し直す必要はありません。
- 場所の確認は**サイトごとに1回だけ**。以降は覚えているので、普段の同期は今までどおり（変更のないレポートは通信ゼロ）です。

---

### “Open the blog draft” now opens the right editor

On sites where WordPress core lives in a subdirectory (e.g. `/wp`), the draft was created correctly but the link opened the theme's 404 page.

- **The admin location now comes from WordPress itself** instead of being assembled from the address the REST API answers at.
- **Links already stored are repaired** on the next sync — no need to press the button again.
- The lookup happens **once per site** and is remembered, so routine syncing still costs zero requests for an unchanged report.
