# 0.11.156

### 日本語

- プロジェクトを開いてすぐにSongsなどのタブを追加すると、追加されないことがある問題を修正しました。読み込みが終わると「タブ追加」が使えるようになります。
- タブの追加・録音・キー操作と、プロジェクト検索・エージェントチームの画面を確かめる自動テストを改善しました。

---

### English

- Fixed an issue where adding Songs or another custom tab immediately after opening a project could silently fail. Add tab now becomes available when the project finishes loading.
- Improved automated checks for tab attachment, recording, keyboard controls, project search, and the Agent Team interface.
