### English

- After an update or a restart, the presidents, commanders and autopilot you had running now come back on their own. Before, one leftover record from an earlier update could keep all of them from returning, with no notice.
- Hands-free updates now wait for a running AI command to finish before restarting (at most 15 minutes in total, after which they install as before). So an update no longer leaves a project's autopilot waiting for you to check it.
- If a project still has to wait for your check after a restart, you are told which project and why, in Japanese, instead of it staying silent.
- Subscription login remains in use. Metered inference APIs and API-key fallbacks remain disabled.

### 日本語

- アップデートや再起動のあと、動いていた社長・司令官・自動運転が自分で戻るようになりました。これまでは、前回のアップデートで残った記録1件のせいで、どれも戻らず、知らせも出ないことがありました。
- 自動アップデートは、AI がコマンドを実行している最中には再起動せず、その区切りまで待つようになりました(待つのは合計で最大15分。それを過ぎたら今までどおり入ります)。アップデートのたびに自動運転が「確認待ち」で止まることがなくなります。
- 再起動のあとで確認待ちが残ったプロジェクトは、どのプロジェクトがなぜ止まっているかを知らせるようになりました。
- 契約ログインを維持し、従量課金のAI API・APIキーへの切り替えは無効のままです。
