# 0.11.184

### 日本語

- **アシスタントから各プロジェクトの社長に、伝言や質問を頼めるようになりました。** 「〇〇の社長に△△と伝えて」「〇〇の進み具合を聞いてきて」と頼むと、アシスタントが伝言の案を出します。「送る」を押すとその社長に届き、社長の返事をアシスタントが会話の中で教えてくれます。
- 社長の会話にも、アシスタントから届いた伝言だとわかる形で残ります。社長が決めてはいけないことは、これまでどおりあなたへの質問として上がります。
- 社長の窓口が閉じていればアシスタントが開きます。届かなかったときや、10分たっても返事がないときは、そのことを伝えます(黙りません)。
- iPhone からアシスタントに頼んでも同じように動きます。iPhone のアプリで伝言の案を見るには、iPhone 側の更新が必要です。

---

### English

- **The assistant can now pass a message or a question to any project's
  president.** Ask "tell the president of X …" or "ask X's president how it
  is going": the assistant shows the message first, and once you press Send
  it reaches that president and the assistant tells you the reply in your
  conversation.
- The president's conversation shows the message as coming from the
  assistant. Anything only you can decide still comes to you as a question,
  as before.
- If the president's window is closed, the assistant opens it. If the
  message cannot be delivered, or no reply comes within 10 minutes, the
  assistant says so instead of going quiet.
- It works the same when you ask from the iPhone. Seeing the message before
  sending it in the iPhone app needs an iPhone app update.
