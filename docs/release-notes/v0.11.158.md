# 0.11.158

### 日本語

- **Canvas に図や案を置くだけのカードが、途中で「保留」に停まらなくなりました。** これまでは、作業係が図を Canvas に置いて明るい画面・暗い画面の写真をカードに付けても、プログラムの変更が無いことを「成果が無い」と判定して保留に停め、紛らわしい知らせが届いていました。いまは、作業中に撮った明暗2枚の写真が付いていて、作業場所に書きかけのコードが残っていなければ、そのまま確認待ちへ進みます。プログラムを書くカードで何も保存されていない場合は、これまで通り知らせて停めます。

---

### English

- **Cards whose only output is on a Canvas no longer stall in "blocked".**
  Previously, a worker that placed figures on a Canvas and attached light and
  dark screenshots to the card was still judged to have "no deliverable"
  because it made no code commits, so the card was parked with confusing
  notices. Now, when fresh light and dark screenshots from this run are on the
  card and the worker's workspace has no uncommitted code, the card moves on to
  review. A coding card that saved nothing is still flagged and stopped as
  before.
