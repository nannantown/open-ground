# 0.11.169

### 日本語

- **画面に浮いているアシスタントの送信ボタンを直しました(試験中)。** ボタンの丸をキャラクターの色で塗り、上向きの矢印にして、ひと目で「送る」とわかる形にしました。iPhone アプリの送信ボタンと同じ見た目です。文字を入れていないときは薄く表示され、押せないことがわかります。

---

### English

- **The floating assistant's send button has been redone (in testing).** It is
  now an up arrow on a circle in the character's colour, so it reads as "send"
  at a glance, and it matches the iPhone app's send button. With nothing typed
  it fades, so you can tell it can't be pressed.
