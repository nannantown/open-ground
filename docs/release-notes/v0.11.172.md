# 0.11.172

### 日本語

- **画面に浮いているアシスタントのロゴから、赤いかけらをなくしました。** ロゴの4つのかけらは、どの画面でも同じ色になります。考え中の動きも、色を変えずに明るさだけで表します。

---

### English

- **The floating assistant's logo no longer has a red piece.** All four pieces
  of the mark are the same colour on every screen, and the "thinking" motion
  now shows by brightness alone, without changing colour.
