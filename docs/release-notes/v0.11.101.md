## OPEN GROUND 0.11.101

### ブログに送るレポートを、自分で選べます

0.11.100 の下書き投稿は「WordPress を設定したら**全レポートを自動で送る**」でした。設定される前に方針を変えています — 調査ライブラリには公開向きのレポートと内部作業ログが混ざっているので、全部送るとブログの下書きがゴミ屋敷になるためです。

- **レポートを開くと「ブログへ」ボタン**が出ます（「MARKDOWNをコピー」の隣）。押したレポートだけがブログに行きます。
- **押すとその場で下書きが立ち**、ボタンが「ブログの下書きを開く」リンクに変わります。
- **押した後の同期は自動のまま** — 調査をやり直せば同じ下書きが更新されます。「公開しない・WP側の編集に勝たない・削除に逆らわない・パスワードを漏らさない」の約束もすべてそのまま。
- **押していないレポートには何も起きません。**
- WordPress 未設定のまま押すと、設定への案内が出ます。

> 0.11.100 のまま WordPress を設定すると全レポートが自動で流れます。**設定はこの版に更新してから**行ってください。

### You choose which reports go to the blog

0.11.100 sent **every** report automatically once WordPress was configured. That changed before anyone configured it — the research library mixes publishable reports with internal ops logs, and sending both would flood the blog's drafts.

- **Open a report and press「ブログへ」(Send to blog)** — next to the copy button. Only pressed reports go.
- **The draft appears immediately**, and the button becomes a link to it.
- **After the press, the sync stays automatic** — a redone report updates the same draft, and every promise holds: drafts only, your WP-side edits win, deletes stand, the password never leaks.
- **Unpressed reports are never touched.**
- Pressing before WordPress is connected points you at Settings.

> On 0.11.100, configuring WordPress still auto-sends everything. **Update to this version before connecting your site.**
