# 0.11.167

### 日本語

- **「やり直す」で再開したカードが、古い完了記録で「統合待ち」に上がってしまう不具合の残りを直しました。** 0.11.166 で直したのはアプリが動き続けている間の経路でした。今回は、やり直しの直後にアプリが再起動した場合と、Board の「実行」ボタンで手動で再開した場合も塞ぎました。やり直しを始めるときに前回の古い「終わりました」の記録を消すので、新しい作業が自分で終わったと伝えるまでは上がりません。
- 作業中の担当がいる作業場所では、その記録を消しません。

---

### English

- **Fixed the remaining cases where a card resumed with "Redo" could jump to
  "waiting to integrate" on an old "done" record.** 0.11.166 fixed this while
  the app keeps running; this release also covers an app restart right after
  the redo, and a manual restart with the Board's Run button. The previous
  attempt's old "done" record is cleared when the redo starts, so the card
  moves up only when the new work reports that it has finished.
- The record is never cleared while a worker is still active in that folder.
