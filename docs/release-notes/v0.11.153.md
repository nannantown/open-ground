# 0.11.153

## 社長への返事がすぐ届くようになりました

- **社長の窓口が空いていれば、司令官からの返事や知らせが1分以内に届きます。** これまでは、社長の最後の返事に番号付きの箇条書きがあると「選択画面が開いている」と読み違えて配達を止め、アプリを再起動するまで「(約N分前の返事)」として持ち越されることがありました。
- **本物の選択画面が出ているあいだは、今まで通り打ち込まずに待ちます。** 複数選択の質問で「Submit」にカーソルがある画面も、選択画面として正しく見分けます。
- 配達を5分以上待たせたときは、その理由がエンジンの記録に1行残ります。

## iPhone シミュレーターの片付けをより慎重に

- 閉じるのは「作業係が起動したと確実に言えるもの」だけです。迷ったら閉じずに残します。
- **作業係が起動したシミュレーターと同じ名前のものを、あなたが使っていれば閉じません。** 作業係の分がすでに止まっていても同じです。

---

## Replies reach the president promptly

- **When the president's desk is free, the commander's replies and notices
  now arrive within a minute.** Previously a numbered list at the end of the
  president's last answer was mistaken for an open chooser, holding delivery
  until the app restarted, when the replies arrived late as
  "(about N minutes ago)".
- **While a real chooser is on screen, nothing is typed into it — as
  before.** A multi-select question with the cursor on "Submit" is also
  recognised as a chooser.
- When a delivery has been held for more than five minutes, the reason is
  written to the engine's log in one line.

## More careful simulator cleanup

- Only a simulator a worker certainly booted is closed; when in doubt it is
  left running.
- **A simulator is not closed if you are using one with the same name as the
  one a worker booted** — even when the worker's own device has already
  stopped.
