# 0.11.141

## 自動更新のあとに「全員止まった」の誤報が出なくなりました

**実現されること**

- **自動更新でアプリが再起動しても、作業が実際に続いているあいだは「全員止まった」の知らせが出なくなりました。** 司令官が担当を立て直している途中も同じです。
- **本当に誰も作業を進めていないときは、今までどおり必ず知らせが出ます。** 担当の画面が開いたまま長く何もしていない場合も「止まっている」と数えるので、知らせが埋もれることはありません。

---

## No more false "everyone stopped" alarm after an auto-update

- **After an auto-update restart, the "all workers stopped" alarm no longer
  fires while the work is actually continuing** — including while the
  commander is bringing a worker back.
- **When nobody is really moving the work forward, the alarm still fires as
  before.** A worker screen left open but idle for a long time counts as
  stopped, so the alarm is never hidden behind it.
