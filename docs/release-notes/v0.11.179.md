# 0.11.179

### 日本語

- **使用量の上限に当たった作業係を、上限が明けるまで起こし直さないようになりました。** これまでは、上限に当たったモデルの枠がまだ使えないのに、同じカードを約1分おきに何度も起動し直しては即止まる空回りが起きることがありました。いまは、ほかに使えるモデルの枠があればそちらで1回だけ試し、なければカードを待たせて、上限が明けてから普通に再開します。
- **「目安を超えて作業係を動かした」の回数が、実際に起動した分だけを数えるようになりました。** 起動の前後の記録まで1回と数えて、回数が水増しされていました。

---

### English

- **A worker that hits a usage limit is no longer relaunched until the limit
  resets.** Before, while the limited model was still unavailable, the same
  card could be relaunched about once a minute and stop again at once. Now,
  if another model is available it gets one try there; otherwise the card
  waits and starts normally once the limit resets.
- **The "workers launched over the guideline" count now counts real launches
  only.** Notes written around a launch were being counted as launches too,
  inflating the number.
