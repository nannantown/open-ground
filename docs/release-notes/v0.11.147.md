# 0.11.147

## 畳んだ席が、名前の読めるアイコンの列に

**実現されること**

- **畳んだ司令官・作業係の席は、キャラクターのアイコンが縦に並ぶ細い列になりました。** 名前はアイコンの下に横書きで出ます(縦書きはやめました)。
- **名前は1回だけ出ます。** 席を開くとその席は列から消え、見出しに「ワーカー2」のように、列と同じ名前で1回だけ出ます。
- **列の印と見出しの状態がいつも同じになりました。** 動いている席だけアイコンが動いて印が光り、止まっている席は薄く表示されます。マウスを乗せると名前と状態が出ます。

## Folded seats become a readable icon rail

- **Folded manager and worker seats are now a narrow column of character
  icons**, each with a short horizontal name underneath — no more vertical
  text.
- **Each name shows once.** Opening a seat removes it from the rail; its
  header carries the same name as the rail ("Worker 2").
- **The rail and the seat header always agree.** Only working seats animate
  and light their lamp; idle ones are faded. Hover shows the name and state.
