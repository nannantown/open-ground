# 0.11.192

### 日本語

- **プロジェクトに追加したタブが、アプリの更新や再起動のあとに外れていることがある問題を直しました。** ボードにカードを足すときの保存で、そのプロジェクトに付けたタブ・タブの並び順・説明文まで消えてしまうことがありました。今は、保存で送られてこなかった項目は前の値のまま残ります。

---

### English

- **Tabs you added to a project no longer drop off after an app update or
  restart.** Saving a new Board card could also erase the project's attached
  tabs, tab order and description. Now anything a save does not send keeps
  its previous value.
