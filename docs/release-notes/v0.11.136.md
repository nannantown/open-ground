# 0.11.136

## ウィンドウにバージョン番号・Canvas の文字色の仕上げ

**実現されること**

- **アプリのウィンドウのタイトルに、いま動いているバージョン番号が出るようになりました。** 自動更新のあとも、新しい番号に変わったことがひと目で分かります。
- **Canvas の文字色の自動判定を仕上げました。** 文字の箱が枠や図形の縁に少しかかるだけで色が変わって読めなくなることがなくなりました。自動で折り返す長い文章も、文章全体がどこにあるかで色を決めます。要素の多い大きな Canvas でも、ドラッグが重くなりにくくなりました。
- (Swarm) 質問に答えたり取り下げたりすると、社長の窓口にも「答え済み」「取り下げ済み」と伝わるようになりました。答え終わった質問を「判断待ち」と言い続けることがなくなります。
- (Swarm) 自動更新で再起動した直後に、「稼働中の担当が0になりました」という誤った知らせが出なくなりました。作業の再開が済むまで少し待ってから判断します。
- (Swarm) Canvas を扱う作業では、仕上げる前にライトとダークの両方で画面を撮って、文字が読めるかを確かめるようになりました。

## Version in the window title, Canvas text colour polish

- **The window title now shows the running version**, so after an automatic
  update you can see at a glance that the new version is live.
- **Canvas text colour judging is finished.** A text box that only grazes the
  edge of a frame or shape no longer flips to an unreadable colour, and long
  soft-wrapped paragraphs are judged by where the text actually sits. Dragging
  on large canvases with many elements is lighter too.
- (Swarm) Answering or dismissing a question now tells the president desk it is
  answered / withdrawn, so a closed question is no longer reported as pending.
- (Swarm) No more false "no workers are running" alert right after an
  auto-update restart; the engine waits for the resume to finish first.
- (Swarm) Work that touches a Canvas now takes light and dark screenshots to
  check the text is readable before it is delivered.
