# 0.11.119

## 設定から切り替えられる worker の試験スイッチ

**実現されること**

- 「worker に『開く前に絞る』を指示する」が、**設定画面のスイッチ**になりました。ターミナルでコマンドを打つ必要はありません。
- **効果はまだ確認できていない**ことを、スイッチの説明文がそのまま書いています。6 回の計測で費用が 7.6% 安くなりましたが、オフのままでも 22% ばらつくので、差とは言えません。オンにしてカードを 6 枚ほど流してから決めてください。
- **オフに戻すと、worker への指示文が元と 1 バイトも同じに戻ります。**ほかには何も変わりません。再起動も不要です。
- 場所: 設定 → 詳細設定 → 「Swarm worker の試験(計測中)」。Swarm を使っている場合だけ出ます(使っていない人に、何も変えないスイッチを見せないため)。

**内容**

この試験は GitHub Trending の棚卸し(`docs/trending/`)から来ています。道具そのものではなく、考え方だけを 1 行の指示として取り込んだものです。ファイルを次々に開く代わりに、まず 1 回の検索で必要な行だけを出させ、その出力だけを読ませます。

同じ棚卸しから来たもう 1 本の試験(「定義だけ引く」)は、実測で**逆効果**(往復 +69%・入力 +65%)だったため、この版では削除済みです。行頭に当てる grep が字下げされた定義を見落とし、エージェントがそれに気づくために余分に往復していました。

やらないこと: 自動でオンにはしません。効果が確認できるまで既定はオフです。

## A Settings switch for the worker trial

- The worker directive "narrow before opening files" is now a **switch in
  Settings**, not a `curl` command. Settings → Advanced → "Swarm worker trials
  (measuring)", shown only when Swarm is on for you.
- The switch's own text states that the effect is **unproven**: −7.6% cost over
  six measured runs, inside the 22% spread of the unchanged setting. Turn it on,
  run about six cards, then decide.
- Turning it off restores the previous worker instruction text **exactly**, with
  no restart. Only cards started after a change are affected.
- The second trial from the same intake ("grep declarations only") is **removed**
  in this release: measured against live runs it was worse — +69% turns, +65%
  input tokens — because its line-start anchor misses an indented definition and
  the agent paid to discover that.
