## OPEN GROUND 0.11.94

### Swarm を「使いたい人だけ」オンにできるように(+ Research の読み取り硬化)

これまで owner だけだった Swarm を、**全ユーザーが自分でオンにできる opt-in** にしました。ただしまだ調整中の機能なので、オンにする前に何が起きるかを正直に伝える注意書きを出します。安全かどうかはコードベースの並列監査で確認済みです(結論: ローカル単一ユーザーのアプリなのでセキュリティ上は問題なし・製品成熟度に鋭利な角があるので opt-in+注意書きが正解)。

- **Swarm(試験運用)トグル** — 設定 → 詳細 に追加。オンにすると Swarm タブが現れます。既定はオフ。**macOS のみ**(安全ガードが Windows で未検証のため、Windows は当面 owner 限定)。
- **正直な注意書き** — オンにする前に開示: あなた自身の Claude サブスクを使い複数セッションを同時に走らせることがある/ワーカーは許可確認をスキップした Claude を隔離コピーの中で実行する/通知は当面日本語のみ/サポート対象外。
- **Research の硬化** — レポートの要点抽出・質問に使う Claude セッションに、ツール拒否リスト(Bash・書き込み・ネットワーク・委譲)を構造的に付与しました。信頼できない Web/SNS 由来の内容の上を走る際の安全マージンです。読み取り(Read)だけを許可します。
- Research タブ自体は従来どおり全員が使えます(サーバ側で元から開いています)。X クッキーの ToS 注意・ローカル保存の約束は既存のとおり。

**変わらないこと**: owner の実験トグルはそのまま。sandbox / persona は引き続き owner 限定(opt-in では開きません)。

### Turn Swarm on if you want it (+ Research read-only hardening)

Swarm was owner-only; now **any user can opt in** to it themselves — behind an honest "still being tuned" warning, since it is not fully polished. Whether that is safe was checked by a parallel codebase audit (verdict: safe in the security/tenancy sense — a loopback-only single-user app — with real product-maturity edges, so opt-in + a warning is the right shape).

- **Swarm (experimental) toggle** — in Settings → Advanced. Turning it on reveals the Swarm tab. Off by default. **macOS only** (the safety guard is unmeasured on Windows, which stays owner-only for now).
- **Honest warning** — before you turn it on: it uses your own Claude subscription and can run several sessions at once; workers run Claude with tool-permission prompts skipped, inside isolated copies of your project; notifications are currently Japanese only; not covered by support.
- **Research hardening** — the Claude session that distills and answers questions about reports now carries a structural deny-list (Bash, writes, network, delegation), leaving only read tools — a safety margin when it runs over untrusted web/SNS content.
- The Research tab stays open to everyone (already open server-side); the existing X-cookie ToS notice and local-only promise are unchanged.

**Unchanged:** the owner experiment toggles; sandbox / persona stay owner-only (the opt-in never opens them).
