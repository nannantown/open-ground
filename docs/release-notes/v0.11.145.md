# 0.11.145

## エージェントチームのバーが、開いていたらそのまま開いて出るようになりました

**実現されること**

- **バーを開いたまま一覧(Ground)に戻り、同じプロジェクトに入り直すと、バーは開いたまま・高さもそのままで出ます。** 閉じていたら閉じたままです。
- **プロジェクトごとに覚えます。** 別のプロジェクトには影響しません。初めて入るプロジェクトは今までどおり閉じた状態で始まります。アプリを再起動しても最後の状態が残ります。

---

## The Agent Team bar stays open if you left it open

- **Leave the bar open, go back to Ground and re-enter the project — the bar
  is still open, at the same height.** Folded stays folded.
- **Remembered per project**, across app restarts. A project you have never
  opened the bar in still starts folded.
