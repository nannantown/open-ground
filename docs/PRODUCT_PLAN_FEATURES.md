# OpenGround Free・Pro・Ownerの機能分け

2026-10-16。利用者向けの整理案。現行実装と、これまで確認した製品方針をもとに分類した。
**このリストの作成だけで権限・価格表・画面を変更しない。追加の有料差分は未決定。**
実装・検証の進捗は [PRODUCTIZATION_PROGRESS.md](./PRODUCTIZATION_PROGRESS.md)、
公開条件は [PUBLIC_LAUNCH_PLAN.md](./PUBLIC_LAUNCH_PLAN.md) を参照する。

| 区分 | 役割 | 料金・権限 |
| --- | --- | --- |
| Free | 自分で操作するプロジェクト・タスク・ターミナルの作業場 | 月額0円。基本操作はアプリへのログインなしでも利用 |
| Pro | Freeの全機能と、作業を補助する自動処理 | 月額2,980円。現行の追加機能はSwarm。初回はmacOS |
| Owner | Free・Proの全機能と、制作・調査・運営・実験の高度機能 | 販売プランとは別のアプリ管理者権限。Pro購入では付与しない |

## Freeに入れる機能

ProとOwnerもすべて利用できる。既存の複数プロジェクト・複数ターミナルを有料側へ移さず、
新しい課金上限を追加しない。「無制限」の性能保証を意味するものではない。

| 分野 | 入れるもの |
| --- | --- |
| プロジェクト管理 | 新規作成、既存フォルダの取込、一覧、検索、切替、名前・説明の編集、説明生成、登録解除 |
| Groundの整理 | カードの移動・配置・グループ、フレーム、テキスト・付箋、拡大縮小、作業状態の表示 |
| Boardの手動管理 | タスクの作成・編集・移動・削除・複数操作、下書き、担当者、優先度、難易度、依存関係 |
| タスクの資料 | 画像添付、ターミナル入力への挿入 |
| 手動でのAI作業 | タスクを自分で実行、実行既定値の設定、自分で依頼するClaudeレビュー |
| 複数ターミナル | プロジェクトごとの複数ペイン、命名、並列表示、通常シェルとClaude Codeの操作 |
| ターミナルの基本操作 | 入力・貼付・リサイズ・停止・再接続、ペイン設定の保存 |
| 開発ツールとの連携 | Finder・エディタで開く、ブランチ操作、差分・PR状態の確認、手動のworktree管理。GitHub等の設定は必要に応じて利用 |
| 利用状況・通知 | 利用枠・トークン内訳、通知、完了音、音量・試聴 |
| 安全性・データ保全 | 保存失敗・破損の検知、既存の世代バックアップ、停止・手動復旧の導線、業務モード |
| 基本設定・ヘルプ | 日英切替、テーマ、表示名、既定の作成先、Claude接続確認、自動更新、マニュアル、更新履歴・バージョン |
| アカウント・問い合わせ | 任意のログイン・ログアウト、プラン確認・購入入口、契約管理・解約への入口、フィードバック送信 |

- Groundの整理機能と、Owner専用のプロジェクト内Canvasは別機能。
- 自分でClaudeにレビューを頼む操作と、Proの自動的な独立レビュー・差し戻しは別機能。
- 自動の世代バックアップ対象は現状、設定・登録一覧の `settings.json` とGround配置の
  `canvas.json`。全データの自動バックアップ・移行機能として販売しない。
- ペイン設定の保存・再接続は、アプリ終了後に任意のシェルプロセスが復活する保証ではない。
- 課金が失効しても、既存のプロジェクト・タスク・設定を消さず、状態確認・停止・契約管理を残す。

## Proに追加する機能

**以下は現行の実装上の差分。新しい作業環境の有料差分を確定したリストではない。**
AI利用料は本人のAI契約によるもので、OpenGround Proの料金にAI利用枠を含めない。

| 分野 | Freeへの追加内容 |
| --- | --- |
| Swarmの利用 | 各プロジェクトの下部バーから有効化・操作。常時開いた専用タブを増やさない |
| AIへの仕事の割当 | 補給官・司令官・Worker、自動配車、Workerによるタスク実行 |
| 自動監視 | Worker・進行状況・利用枠の監視、利用枠に応じた待機・再開制御 |
| 自動復旧 | 停止・異常の検知、再試行・再起動・継続処理。常に成功する保証はしない |
| 独立レビュー | 実装担当と分けたレビュー、差し戻し、再実装・再レビューの進行管理 |
| 承認・質問の管理 | 人の返答が必要な作業の保留、質問と回答、統合待ちの確認・操作 |
| 自動処理の詳細設定 | Swarmの有効化同意、使用可能モデルなど既存の実行設定 |

追加の有料価値は「まず既存機能の品質を完成させ、有料差分は後で決める」という回答に沿って保留。
複数ターミナル・プロジェクト数への課金制限、保存レイアウト・プリセット・統合ダッシュボード等を
この整理を理由に新設しない。現状ではProの追加機能が自動処理中心である点は、そのまま明示する。

## Ownerのみに入れる機能

OwnerはOpenGround全体の管理者。共同編集プロジェクトの所有者とは別の権限。
既存の高度機能と保存データを維持し、一般ユーザー向け画面には並べない。

| 分野 | Owner専用にするもの |
| --- | --- |
| プロジェクト内Canvas | 図形・付箋・画像・画面・レイヤー・履歴、AIによる生成・修正 |
| Research | 調査レポートの一覧・閲覧、再調査、要約、質問、調査チャンネルの診断・認証設定 |
| ブログ連携 | WordPress接続設定、選択レポートの下書き送信・追随、送信記録と復旧操作 |
| Songs | 既存のNENEとの起動・表示連携。録音・再生・書出し等は別のNENE本体も必要 |
| カスタムタブ | ローカルのタブ作成・編集・取付・表示、タブの追加・非表示・並べ替え |
| Skills管理 | Global／Project Skillsを閲覧・生成するOpenGround内の管理UI |
| Assistant | 画面内アシスタント、写真・会話・提案、提案からBoardへの追加、長期メモ・保持設定 |
| iPhone連携 | ペアリング、暗号化中継、会話・通知、APNs等の設定 |
| 自動の分析・提案 | 日次の燃料レポート、改善提案 |
| 実験・開発用設定 | Worker試行、sandbox等の実験スイッチ、新しい実験機能 |
| 表示の確認 | 一般ユーザー表示のプレビュー。実データへの操作であり、テスト用アカウントの代用ではない |
| 運営者用の管理 | フィードバック受信箱。現行は専用のサーバー設定・管理者判定も必要で、ProやOwnerロールだけで公開しない |

- Skills管理UIの制限は、利用者自身がClaude Codeで既存のSkillsを使うことを制限しない。
- WordPress連携は現状「下書き」の範囲。記事の一般公開操作・画像同期・複数サイト同時管理を
  実装済み機能として含めない。
- Ownerを外した場合も保存済みCanvas・調査・Songs連携・カスタムソース・WordPress記録を消さない。

## 設定画面も同じ区分にする案

| 表示先 | 設定項目 |
| --- | --- |
| 全員の基本設定 | プラン、言語、表示名、自動更新、完了音・音量、更新履歴・バージョン。テーマは既存のToolbar入口 |
| 全員の詳細設定 | 既定の作成先、Claude接続確認、業務モード |
| Pro／Ownerの自動処理設定 | Swarm有効化、使用可能モデルなど |
| Ownerの高度な設定 | 調査チャンネル・X認証、WordPress、iPhone・会話メモ、Worker試行、実験、一般ユーザー表示プレビュー |
| 運営者の管理 | 専用設定がある環境だけフィードバック受信箱を表示 |

一般ユーザーのプロジェクト画面は **Board・Terminal** を中心にし、Proでは必要なときにSwarmを開く。
OwnerだけCanvas・Research・Songs等のローカルタブを追加する。今回、設定の配置自体は変更していない。

## 分類を保留するもの・提供済みにしないもの

| 項目 | 今回の扱い |
| --- | --- |
| 共同編集・招待・共有Board | 既存の設定・アクセス・データを維持。実2ユーザー試験と公開範囲・運営負担の判断まで、新たなFree／Pro境界を設けない。共有Canvasには別途App Owner権限が必要 |
| Codex／ChatGPT接続 | 未実装。問い合わせ提出と利用許可を区別し、最初の公開に含めた機能として案内しない |
| 新しいPro向け作業環境 | 内容・実装とも未決定。既存Freeを狭めることで差分を作らない |
| WindowsでのPro新規購入・自動処理 | 実機受け入れまで閉じる現行方針。既存の契約管理・Owner権限は保持 |
| カスタムタブ市場・配布、旧Chats等 | 廃止済みのため復活させない。残存データは消さない |

この分類は公開可能性の証明ではない。実認証・実決済、非Owner Proでの実Claude、
署名・公証付きMac実機、外部連携、提供元の適用条件等の未確認事項は進捗資料のまま残す。
