# iPhone を画面ロック中でも呼び出すための「Apple の鍵」の作り方

これを1回やると、iPhone をロックしてポケットに入れたままでも、社長窓口に知らせが来たら
イヤホンで聞こえるようになります。料金はかかりません(お持ちの Apple Developer 登録の中で作れます)。
所要時間は5分ほどです。

## 1. Apple のサイトで鍵を作る(Mac のブラウザで)

1. <https://developer.apple.com/account> にサインインします。
2. 「Certificates, Identifiers & Profiles」を開き、左の一覧から **「Keys」** を選び、**「+」** を押します。
3. 「Key Name」に分かりやすい名前を入れます(例: `OPEN GROUND 呼び出し`)。
4. **「Apple Push Notifications service (APNs)」** にチェックを入れ、横の **「Configure」** を押します。
   - 環境(Environment)を聞かれたら **「Production」** を選びます(TestFlight で入れたアプリはこちらです)。
   - 種類を聞かれたら **「Team Scoped」** のままで大丈夫です。
5. 「Save」、「Continue」、「Register」の順に押して進みます。
6. **「Download」** を押すと、`AuthKey_XXXXXXXXXX.p8` というファイルが Mac の「ダウンロード」に保存されます。
   - 注意: このファイルは **1回しかダウンロードできません**。なくした場合は、同じ画面で鍵を作り直せば大丈夫です。
   - 人に送ったり、メールやチャットに貼ったりしないでください。
7. 同じ画面で、鍵の名前の下に出ている **「Key ID」**(英数字10文字)を控えます。
8. 右上のアカウント名を押し、「Membership details」に出ている **「Team ID」**(英数字10文字)を控えます。

## 2. OPEN GROUND に入れる(1回だけ)

1. OPEN GROUND の **設定 › iPhone** を開きます(iPhone とつないである状態で出てきます)。
2. **「Apple の鍵を入れる」** を押します。
3. ファイル選びで、さきほどの `.p8` ファイルを選びます。
4. 「Key ID」と「Team ID」の欄に、控えた10文字をそれぞれ入れて **「保存」** を押します。
5. 表示が「Apple の鍵は設定済み・iPhone 待ち」になれば、Mac 側は完了です。
   - 「正しくありません」と出たら、ファイル・Key ID・Team ID の取り違えがないか見直してください。

鍵はこの Mac の中にだけ保存され、外には出ません。画面に表示されるのも Key ID だけです。

## 3. iPhone 側

1. iPhone の OPEN GROUND アプリを開き、**「ロック中も聞く」** を押します。
2. Mac の設定画面の表示が **「ロック中も iPhone を呼び出せます」** に変われば準備完了です。

## 4. 確かめる(社長と一緒に)

iPhone をロックしてイヤホンを付けたまま、社長窓口に知らせが届くのを待ちます。
声で聞こえれば完了です。聞こえなかったときは、社長に「ロック中に聞こえなかった」と伝えてください。

## うまくいかないとき

- Mac の OPEN GROUND が起動していないと呼び出せません(知らせを送るのは Mac です)。
- 業務モードの間は呼び出しません(つながり自体を止めています)。
- Mac に入れておける鍵は1つだけです。ふだん使う TestFlight 版は「Production」の鍵で動きます。
- 開発中のアプリ(Xcode から直接入れたもの)で試すときだけは、「Sandbox」の鍵が必要です。
  その間は手順1で Sandbox の鍵を作り、手順2の「鍵を入れ替える」で入れ替えてください。
  TestFlight 版に戻るときは、Production の鍵にもう一度入れ替えます。
- 設定画面に「ロック中の呼び出しが止まっています: Apple が鍵を受け付けません」と出たら、
  鍵の種類(Production / Sandbox)か、ファイル・Key ID・Team ID の組み合わせが合っていません。
  正しい鍵を入れ直すと(同じ鍵をもう一度入れても)、次の呼び出しから、また試します。
- 「ロック中の呼び出しが止まっています: iPhone のアプリを開き直してください」と出たら、鍵ではなく
  アプリ側の問題です。鍵は入れ替えず、iPhone のアプリを一度開いてください。
