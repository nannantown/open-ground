# 一枚企画: Research レポートをブログ(eigotrip.com)へ下書き自動投稿

| 欄 | 内容 |
|---|---|
| **きっかけ** | 2026-08-28、オーナーが Research タブのスクショを見せて「どれだけ調べてもこんな感じの UI で結局みにくい」。読む場所を作り込むのをやめ、既に持っている読みやすい場所(WordPress ブログ eigotrip.com)へ出すことにした。 |
| **どんなときに使うか** | 調査カードが終わってレポートが `docs/research/` に落ちたとき、何もしなくても eigotrip.com の**下書き**に届いていてほしい。そうすれば WordPress の見慣れた画面で読み、直し、公開ボタンを押すだけになる。 |
| **かける量 (Appetite)** | 1日。超えるなら機能を削る(UI 表示や複数サイト対応を落とす)。 |
| **やらないこと (Non-goals)** | ⓪**全レポートを自動では送らない**(2026-08-28 改訂 — 出荷同日にオーナー指摘。調査ライブラリには内部作業ログも混ざるため、送るのは「ブログへ」ボタンを押したレポートだけ。押した後の同期は自動)。①**公開しない** — 作るのは常に下書きまで。公開はオーナーが WP 側で押す(SNS 引用を含むレポートが無審査で世に出る事故を構造で防ぐ)。②**WP 側の編集に勝たない** — オーナーが WP で1文字でも直した下書きは、以後こちらから上書きしない。③**削除に逆らわない** — WP 側で消された下書きは再作成しない(ただしレポート自体が書き直されたら「やり直し」なので新しい下書きを作る)。④画像・添付は同期しない(v1)。⑤wordpress.com 形式は対象外(自前 WP のみ)。⑥複数サイト対応はしない。 |
| **言ってよいこと** | 「下書きを作成しました」「更新しました」「WordPress 側で編集されているため上書きを止めています」「WordPress 側で削除されているため再投稿しません」「投稿に失敗しました(理由)」。**言ってはいけない**: 「公開しました」(公開はしない)、パスワードを含むエラー文。 |
| **材料はあるか** | ある。レポート = `docs/research/*.md`(listResearchReports が索引済み)。宛先 = WP REST API(自前 WP に標準搭載、アプリケーションパスワードで認証)。新たに保存が要るのは ①接続設定(Settings.wordpress: baseUrl / username / appPassword)②投稿台帳(レポート⇄WP記事IDの対応 + 最終送信ハッシュ + WP側更新時刻)。台帳が無いと「同じレポートが毎回新しい下書きになる」ので必須。 |
| **いちばん危ういところ** | **実現性ではなく信頼**: オーナーが WP 側で直した下書きを、次の自動更新が黙って上書きしたら、この機能は二度と信用されない。確かめ方 = WP の `modified_gmt` をこちらの最終送信時刻と突き合わせ、ズレていたら上書きせず「編集済み」と表示する。この判定を mutation で赤を実測してから出す。 |
| **できたと言える状態** | 実機で: 調査レポートが増える → 数分内に eigotrip.com の下書き一覧に現れる → WP で本文を1行直す → レポートを書き直しても WP の直しが消えない(「編集済み」表示になる)。 |

## 追記(2026-09-02) — 編集リンクは WordPress 本人に聞く

実測: オーナーのブログは home が `https://eigotrip.com`、WordPress 本体が `/wp` の中。
REST は home 基準(`/wp-json/...`)なので**投稿は全部成功**していたが、編集リンクを
`baseUrl + /wp-admin/...` で組んでいたため存在しないURLになり、WordPress が
**テーマの404**を返していた(= 動いている機能が壊れて見える)。

修正: 投稿時に `/wp/v2/settings` の `url`(= `siteurl`)を**サイトごとに1回**取得して
台帳(`blog-publish.json` の `adminBase`)に記憶し、そこを基準にリンクを作る。既存の
リンクも次の sweep で付け替える(通信は増やさない・下書き自体は触らない)。取得できない
サイトでは従来どおり `baseUrl` にフォールバック。歯は `blogPublish.test.ts`
(サブフォルダ構成の偽サイト・リンク文字列を固定・修復・毎回取得しない)。
